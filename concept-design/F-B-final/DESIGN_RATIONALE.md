# DESIGN_RATIONALE — 专项训练页 F-B 设计说明

## 定位

F-B = Warm Branded Learning Panel（温暖品牌化学习面板）。
不是新世界观，不是地图，不是后台 Dashboard——是现有 Number Sense Lab
首页视觉语言下的一张「分组双列主题面板」。

## 关键决策

1. **继承而非发明。** 奶油白底、青绿主色、圆角卡片、浅色 icon 容器、
   吉祥物作为品牌锚点，全部来自现有首页 DNA。本页是首页的兄弟页面。
2. **分组靠底色，不靠卡片边框。** 三个分组使用极浅蓝 / 浅橙 / 浅薄荷容器，
   组内 tile 才是白色小卡。层次由「底色 → tile → 图标 chip」三级构成，
   避免了上一版「大白卡片墙」的均质感。
3. **图标承担语义，状态退后。** 图标放大到 56–72px 且有明确数学语义
   （2×2 面积格 / 立方体 / 上升阶梯 / 点阵 / 拼合 / 横线分数↔小数 /
   一变二 / 补缺圆环）；状态文字弱化为小灰字，不用 Badge、不用红黄绿。
4. **吉祥物克制出现。** 仅页头右侧，高度 ≤ 标题区，不加气泡插画；
   「今天想练哪个？」降级为普通小字。
5. **组色是辅助，不是彩虹。** 蓝 / 橙 / 薄荷只出现在组底色、组色点和
   该组图标色系内，全局主色仍是青绿。

## 为什么它和首页是同一个 App

- 同一背景色、同一主色、同一圆角与轻阴影逻辑；
- 同一吉祥物（复用现有 welcome 姿态素材，未重绘人物）；
- 同一排版层级：大标题 + 小副标题 + 分段控件；
- 图标容器语言与首页功能入口一致（浅色 chip + 图形）。

## 为什么适合 12～15 岁

- 信息直给：8 个入口一屏三组，扫读路径最短，符合「每天 5～10 分钟」；
- 有一点亲和力（吉祥物、小字问候、柔和配色）但不幼儿化；
- 图标语义尊重数学本身（横线分数、面积格、点阵），把学习者当聪明人。

## 为什么优于旧版白卡片墙

- 旧版：8 张等大白色厚卡堆叠，组间无区分，图标小且灰，页面均质、像目录；
- F-B：组底色先行分区，tile 紧凑双列，图标成为视觉主角，状态降噪，
  页面重量减半，探索感来自「分组场景」而非插画。

## 扩展性

- tile 网格为双列流式布局，新增 domain 即新增 tile，组内容量 2→4→6 不需改版；
- 新增分组 = 新底色 + 新组色 token，结构与 token 体系不变；
- 图标规格固定（256/512 透明 PNG，同色系的 semi-flat），新增图标有明确生产规范；
- 知识地图 Tab 已在 IA 中占位，未来接入不影响本页布局。

## 边界声明

- 未改信息架构、未改 domain 数量与 ID、未加知识地图内容；
- 未引入排行 / 积分 / 金币 / 关卡等游戏化元素；
- 所有文字均由程序渲染，图片资源不含烘焙文字；
- 分组背景与装饰由 CSS 实现，资源包只含真正需要位图的内容。
