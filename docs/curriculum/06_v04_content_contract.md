# 2. 两种课程意图，一种技术表示

Recall Fact：立方、常见幂、凑整乘积锚点。目标是这条关系逐渐能直接想起来。

Strategy Fluency：半数、补数。14 条和 12 条是策略的代表题，不是背诵清单。半数的策略是「整十和个位各半」。补数的策略是「个位凑 10，十位凑 9」。学生会了之后，应当能用同一策略处理没有入选的同类数，例如 82 的一半。那是课程成功标准，不是再加题的理由。

两类都写成现有的 relation，走现有 Scheduler、错题本和掌握四态。不因为课程意图不同就新增 Runtime 类型、掌握对象或调度桶。

# 4. 五个域

共同规则：

- `level` 都是 `core_recall`。只有这一层进入抽题和掌握。
- `direction` 都是 `forward`。本轮不做反向。
- `answer_type` 都是 `integer`。不新增答案类型。
- `entry_after` 都是空。没有 relation 级前置，也没有域级前置。
- tier 只表示进入先后，不表示复习间隔。
- 答错仍是：正确关系，加一句钩子，再按「下一题」。没有「再做一遍」。钩子和相关例的展开仍用现有三层：`relation`、`hook`、`pattern` 与 `frames`。
- 每日训练：该域的文件已经进入发布目录时，这些 relation 和已有域一样可被抽到。
- 专项：一域一张卡，只抽该域。未发布的域继续「敬请期待」。

## 4.1 `cubes`｜立方｜Recall Fact

直接提取 2³ 到 9³。1³ 不收。反向立方根不收。

常见误区写在钩子和 `pattern.check` 里，不另做错误分类器：把 n³ 当成 3n；把 7³、9³ 和平方弄混。

统一结构是「先平方再乘一次」。7³ 和 9³ 诚实标成提取锚点。4³、5³、8³ 用相关例挂上已有平方或幂，不因此再造一条可训练 relation。

## 4.2 `halves`｜半数与翻倍｜Strategy Fluency

只练「这个偶数的一半是多少」。题干形式冻结为：`86 的一半是？`。答案是整数。

不生成 1–100 的半数表。不收整十减半，不收 20 以下，不收奇数。

翻倍不单独出题。反馈相关例里可以出现 `43 × 2 = 86`，那是 supporting example，没有自己的 id，也没有掌握。

## 4.3 `complements`｜补数｜Strategy Fluency

题干冻结为：`37 + ? = 100`。Owner 已批准这次表达调整。课程目标仍是补数感：找凑成 100 所缺的加数。

主提示不得写成 `100 - 37 = ?`，也不得写成普通减法竖式。那会把补数感做成减法执行。

答案仍是一个整数。37 → 63 与 63 → 37 是同一对凑整关系，只训练表里的那一个方向。对偶出现在相关例里，不另建 id。

## 4.4 `powers`｜常见幂｜Recall Fact

恰好这 9 个 id：`pow-2-5`、`pow-2-6`、`pow-2-7`、`pow-2-8`、`pow-3-4`、`pow-5-4`、`pow-2-9`、`pow-2-10`、`pow-3-5`。

没有 `pow-5-3`。4ⁿ、6ⁿ、7ⁿ 不收。只问正向。

同值不同形保持为不同 relation：例如 2⁸ = 256 与已有 16² = 256，2⁶ = 64 与 4³ = 64。它们的题干不同，掌握分开。OQ5 只合并 5³ 这一条事实。

## 4.5 `special_products`｜凑整乘积家族｜Recall Fact

恰好 8 条：25×2、×3、×4、×6、×8，以及 125×2、×4、×8。

25 家族的 family id 是 `f25`，125 家族是 `f125`，类型都是已有的 `scaling`。同族不连成串沿用现有洗牌，不新写规则。

不收 37 家族。37 家族留在将来的「规律探索」，本契约不给它 id。

# 5. 知识网络，只到反馈够用

每个域的可训练集合就是第 4 节的 Core Recall。下面这些只是相关例或以后的地图节点，不进抽题，不进掌握，不进 173：

| 域 | 可训练 | 只作为相关例 |
| --- | --- | --- |
| 立方 | 8 条 | 先平方再乘一次；5³ 与 1/8 家族同值；8³ 与 2⁹ 同值 |
| 半数 | 14 条 | 对应的翻倍，例如 43×2 = 86 |
| 补数 | 12 条 | 对偶搭档，例如 63 和 37 也凑成 100 |
| 常见幂 | 9 条 | 翻倍链；与平方、立方的同值。5³ = 125 只指向 `cube-5` |
| 凑整乘积 | 8 条 | ×25 = ×100÷4，×125 = ×1000÷8；25×3 与 3/4，125×8 与 1/8 |

`frames` 每条最多两帧：一帧是这一步策略，一帧是这条正确关系。不写概念课、例题课、动画。详细课文仍归以后的 Kimi。

# 6. 发布节奏不是调度器

全部发布时，目录顺序是：平方、常用乘积、分数到小数，然后半数与翻倍、补数、立方、常见幂、凑整乘积家族。分批发布时只保留已发布的域，相对顺序不变。这是 `DOMAIN_ORDER` 的登记，不是域级解锁。

一个域进入今日训练和专项，当且仅当它的内容文件被放进当前发布的目录。未放入的域不存在于目录里，卡片保持「敬请期待」。

禁止用新字段、新状态或域级 Scheduler 去模拟「前一域 stable 了再打开」。分批发布就是少放文件，不是少写一条学习规则。

完整 v0.4 内容包的验收总数是 173。只发布若干整域时，总数是 122 加上已发布域的条数，而且每个已发布域必须是整域，不能只放该域的一部分。
