# 1. 新训练域候选

| 候选域 | 内容 | 素材来源 | 备注 |
| --- | --- | --- | --- |
| 立方 | 1³–9³ 及知识地图 | 大九九资料立方表 | 只借用数学事实；初中科学计数法、体积计算有价值 |
| 整数次方 | 2ⁿ（至 2¹⁰）、3ⁿ、4ⁿ、5ⁿ | 大九九资料乘方表 | 与 16²=2⁸、16×8=2⁷ 的 v0.1 关系网天然衔接 |
| 半与倍 | n ↔ n/2、n ↔ 2n（1–100） | 大九九资料半倍表 | 与 ×15 减半变换互为逆操作 |
| 补数 | n → 100−n | 大九九资料补数表 | 减法数感、凑整策略 |
| 相邻数的和与积 | (n, n+1) → (和, 积) | 大九九资料相邻数表 | 与平方差、二次方程根系（韦达定理）衔接 |
| 特殊乘积家族 | 25×k、125×k、37×k | 大九九资料特殊家族表 | 25×4=100、125×8=1000 等；因数超出 v0.1 的 6–19 候选范围，按 Owner Decision 整体留池 |
| 质数相乘 | 7×13=91、7×17、7×19、13×17、13×19、17×19 | 大九九资料质数相乘表 | 91 已在 v0.1；其余留池，服务因数分解数感 |
| 循环小数 | 分母 3、6、7、9、11、12、15 的分数→小数 | 大九九资料分数转小数表 | PRD 明确排除出 v0.1；进入前需决定循环节表示法 |
| 小数 → 分数 | 0.125 → 1/8 等 | 自建 | 被 PRD 待验证问题 5 挡住：是否必须最简分数，决定前不开工 |
| 开方 / 逆问 | 「哪个数的平方是 289」 | 自建 | PRD 排除出 v0.1；平方 Core Recall 稳定后自然衔接 |
| 平方进阶记忆（Advanced Recall） | 21²–30²、尾 5 平方、整十平方等升级为可训练 | `squares.knowledge_map.json` 的 Structured Practice 层 | 自愿扩展，不是默认要求；面向对数字特别感兴趣的孩子 |
