# Number Sense Lab｜数感训练场

# Feedback & Memory Hook Design v0.1（学习反馈设计）

状态：C0 课程内容建议，供 Owner 与 ChatGPT 做 Content Review。

本文定义 v0.1 的反馈层级、Memory Hook 分类体系、每类钩子的教学原理（Teaching Rationale），以及背后的学习科学依据。学生界面永远保持短；完整原理只存在于本课程设计层。

---

# 1. 反馈的三层结构

每条关系的反馈按深度分三层，与运行时 JSON 字段一一对应：

| 层级 | 内容 | JSON 字段 | 呈现规则 |
| --- | --- | --- | --- |
| Level 1 | Correct Relation（正确关系本身） | `relation` | 答错后默认呈现，主角 |
| Level 2 | Short Memory Hook（一句结构提示） | `hook` | 答错后默认呈现，一句话 |
| Level 3 | Pattern / Reasonableness / Related Examples（规律、合理性检查、相关例、分步过程） | `pattern.check`、`pattern.family`、`frames` | 学生主动展开才呈现 |

默认反馈保持短（Level 1 + 2），扩展内容由学生主动展开（Level 3）。这与 UX 契约「答错：画面的主角是正确关系，加上一句结构提示」一致；Level 3 的展开交互是 UX 尚未冻结的部分，内容层先把数据备好，不要求 v0.1 实现展开 UI。

# 2. Memory Hook 分类体系

Memory Hook 不是给每道题编一句顺口溜。v0.1 使用六类钩子，优先级从高到低：

```
数学结构 > 关系/锚点 > 合理性判断 > 视觉辅助 > 人工口诀
```

| 类型 | hook_type | 定义 | v0.1 示例 |
| --- | --- | --- | --- |
| Structure Hook | `structure` | 利用数学本身的结构 | 15²：1×2=2 后接 25；11×12：两头拉开中间放和 |
| Transformation Hook | `transformation` | 把问题变换成已会的形式 | 7/20：同乘 5 凑成 35/100；15×8：8 减半 ×30 |
| Anchor Hook | `anchor` | 从记牢的锚点关系推出 | 3/8 = 3 × 0.125；7/8 = 1 − 0.125 |
| Relation Network | `relation_network` | 把关系串进已有网络 | 16×8 = 2⁴×2³ = 2⁷；91 = 7×13「假质数」 |
| Reasonableness Check | `reasonableness` | 用数量级和边界做校验 | 13²=169 与 14²=196 辨别；17² 必在 256 与 324 之间 |
| Retrieval Anchor | `retrieval_anchor` | 诚实标记：没有更好的技巧，靠间隔提取记牢 | 17²=289；17×8=136 |

v0.1 的 75 条关系中没有使用人工口诀（Rhythm / Verbal Cue）。它没有被永久排除——但对每一条候选口诀，必须证明它比直接计算更简单、不制造新的认知负担，才允许进入。

**Retrieval Anchor 是一等公民。** 强迫每条关系都有「聪明口诀」会生造出比原计算更复杂的伪技巧。对 17² 这样的关系，最好的方法就是诚实的间隔提取——这本身有最强的研究支持（见第 5 节）。

# 3. 每个 Hook 的两层内容

每个重要 Hook 同时存在两层：

**A. Student-facing Hook（学生看到的）**：一句话，在 `hook` 字段。例如 15²：「1 × 2 = 2，后面接 25。」

**B. Teaching Rationale（课程设计层的原理）**：只存在于本文档，回答——基于什么数学结构、是否可迁移、降低了什么认知负担、有无误用风险、哪类学生受益。

## 3.1 尾 5 平方（15²、25²）

- 数学结构：(10n+5)² = 100n(n+1) + 25，恒等式，因此可以写成「一定」。
- 迁移：推广到 35²–95²（知识地图 Structured Practice 层），同规律复用。
- 认知负担：把一次两位乘法换成一次一位乘法 + 拼接，工作记忆占用显著下降。
- 误用风险：只对末位 5 的整数成立；反馈中已写明「末位是 5 的整数平方」，防止过度推广到任意数。
- 适合：所有学生；是最早能获得「我发现了规律」体验的关系。

## 3.2 ×11 两头拉中间加（11×12 等 5 条）

- 数学结构：11×(10a+b) = 100a + 10(a+b) + b。
- 迁移：任何两位乘数；11×19 专门呈现进位情形（a+b ≥ 10），防止学生把规律记成「永远不进位」。
- 认知负担：三步以内完成，低于竖式。
- 误用风险：乘数超过两位时不适用；内容层只选两位乘数，反馈不暗示更大范围。
- 适合：已熟练掌握加法进位的学生。

## 3.3 偶数 ×15 减半 ×30（15×6 等 5 条）

- 数学结构：(2k)×15 = k×30。
- 互证：每条反馈同时给出 10n+5n 分解（如 8×15 = 80+40），因为对部分学生「拆 15」比「减半乘 30」更自然——两条路径指向同一答案，学生任选。
- 认知负担：两种算法都只需一位乘法。
- 误用风险：只对偶数乘数成立；本簇全部选偶数，反馈不暗示奇数情形（13×15 走 10n+5n 拆分，不走减半）。
- 适合：对「减半」操作熟练的学生。

## 3.4 分数锚点倍数（1/4、1/5、1/8 族，11 条）

- 数学结构：分数的倍数即小数的倍数；1 − 1/n 的补结构。
- 迁移：锚点策略可推广到任何单位分数族；也是百分数（0.375 = 37.5%）的预埋路径。
- 认知负担：把除法换成已记锚点的一次乘法或减法。
- 误用风险：锚点本身必须真正记牢，否则倍数一起错——因此 1/8=0.125 单独作为 Tier 2 训练关系，先于其倍数族稳定。
- 适合：所有学生；对「除法恐惧」的学生尤其重要。

## 3.5 凑百变换（/20、/25 族，13 条）

- 数学结构：分数基本性质（分子分母同乘，值不变）。
- 迁移：直通百分数；同时强化「百分之几 = 两位小数」的位值理解。
- 认知负担：一次一位乘法 + 小数定位。
- 误用风险：学生可能忘记「分子也要乘」；frames 分步呈现「×5 → 35/100」正是针对此。
- 适合：已理解分数基本性质的学生（初一已学）。

## 3.6 关系网络（16²、16×8、91、14×16 等 5 条）

- 数学结构：幂运算性质、因数分解、平方差。
- 迁移：把孤立事实编入网络后，提取路径变多（编码变异性），也为代数恒等式预演直观经验。
- 误用风险：14×16 = 15²−1 这类结构需要 15² 已稳定，因此排在 Tier 3。
- 适合：已建立基础锚点后的学生；对数字敏感的孩子会主动发现更多网络。

## 3.7 合理性检查（13²/14² 及全部 `pattern.check`）

- 数学结构：单调性（n² 随 n 增大）、末位分析、区间夹逼。
- 迁移：这是「答案闻起来不对」的能力，可迁移到一切计算的自检。
- 认知负担：不替代计算，只在校验阶段使用，负担极低。
- 误用风险：区间检查只能发现大错，不能验证精确值——反馈中检查与正确关系同时呈现，不单独充当判据。
- 适合：所有学生；是 Number Sense 名称的核心承载。

# 4. 视觉、动效与声音：可选的记忆通道

视觉和声音不是装饰层，而是**可选的记忆通道**；只有当它们强化数学结构、关系或提取路径时，才进入课程设计。

- **Visual Cue（视觉线索）**：`frames` 字段是 v0.1 的视觉通道载体——把 Hook 拆成 2–4 个分步画面（如 15² 的「1 × 2 → 2 → 2|25 → 225」）。它对应双重编码（Dual Coding）：语言 + 视觉空间两条通道同时编码，提取路径更多。
- **Motion Cue（动效线索）**：frames 的逐步出现即最轻量的动效——数字如何拆分、合并、靠近锚点。v0.1 内容层只定义分步结构，具体动效表现属 UI 层。
- **Audio Cue（声音线索）**：内容层不定义声音；按产品契约，音效永远可关闭，关闭后训练完整。任何未来的节奏提示（如 tap → tap → ding）只能强化结构分步，不能成为必要反馈。
- **Delight 与 Memory Cue 的判别**：一个视觉效果（如水滴波纹）如果只是好看，属于 Delight，进 Backlog 观察；只有当它能帮助孩子感知「一个关系扩散到相关关系」时，才有机会升级为 Memory Cue。当前不设计、不开发。

# 5. 学习科学依据

本课程的训练机制与 Hook 设计依据以下有研究支撑的学习原则。区分说明：标注【研究】的是有同行评议证据的原则；标注【经验】的是教学经验推断，效果待真实使用复核。

**Retrieval Practice（提取练习）【研究】**：提取本身就是最强的学习事件。Roediger & Karpicke（2006）的经典实验中，一周后测试组保持率 61%，重学组 40%。这是整个产品「练提取，不练查找」的根基——答题时不提供对照表。

**Spaced Practice（间隔练习）【研究】**：Cepeda 等（2006）综合 254 项研究，分散练习稳定优于集中练习。对应产品的「稳定必须跨天」「答对一次不算掌握」。注意：**Content Tier ≠ Review Interval**——内容的 tier 只表示进入顺序与初始教学建议，复习间隔应由运行时根据学生表现动态决定，不由内容层冻结。

**Interleaving（交错练习）【研究】**：Rohrer & Taylor（2007）最早在数学练习中验证交错优于分块；Rohrer、Dedrick & Hartwig（2020）的随机课堂实验进一步显示，一个月后未预告测试中交错组 61% 对分块组 38%。对应今日训练三域混抽，而不是一次只刷一个域。

**Desirable Difficulties（合意困难）【研究】**：Bjork & Bjork（2011）——提取时略感吃力的条件产生更持久的记忆。对应「错题隔开若干题再出现，而不是紧接着连打」。

**Generation Effect（生成效应）【研究】**：学生自己生成的答案，比直接阅读现成答案记得更牢。对应「学生必须输入答案，而不是从选项中辨认」，以及 A4 纸上自己再写一遍。至于「答错后不立即原题重做、隔开几题再出现」，主要归因于间隔与延迟提取（spacing / delayed retrieval），不归因于生成效应。

**Chunking（组块化）【研究/经验】**：工作记忆容量有限，把 15² 加工成「1×2 接 25」一个组块，释放资源给后续计算。这是 Structure Hook 降低工作记忆负担的机制解释。

**Dual Coding（双重编码）【研究】**：语言与视觉双通道编码提供更多提取路径。对应 frames 分步视觉呈现。

**Elaboration（精加工）【研究】**：把新事实与已知建立联系（91 = 7×13 接「假质数」辨别）比孤立记忆保持更好。对应 Relation Network 钩子。

**Progressive Disclosure / Scaffolding（渐进披露 / 脚手架）【研究/经验】**：信息按需要分层呈现，避免一次倾泻造成负荷。Level 1→2→3 的反馈层级属于这一类：默认只呈现正确关系和一句 Hook，更多解释由学生主动展开。

**Worked Example Fading（示例淡出）【研究/经验】**：从完整示例逐步撤掉支架，最终独立提取。它发生在**跨多次训练**的时间轴上——早期答错时看到完整关系与分步 frames，随着关系变稳，学生越来越不需要展开提示，最终纯提取。它不用于解释单次答错页面里的 Level 1→2→3。

**Cognitive Load（认知负荷）【研究】**：反馈一屏一个钩子，不塞理论；默认只呈现 Level 1+2。任何「为了完整」而堆砌的解释都会挤占用于编码的工作记忆。

**Estimation / Reasonableness（估算与合理性）【研究/经验】**：数感训练（数量级、数轴表征）在干预研究中显示对算术能力的中等效应量（d ≈ 0.54，Kuhn & Holling 等的小学干预研究线）。对应 Recognition / Estimate 层与全部 `pattern.check`。

**Number Sense Development（数感发展）【经验】**：「哪些值得记住、哪些值得会推、哪些只需会估」的三能力划分（Recall / Derive / Recognize）是本课程的教学立场，其分层效果属于待真实使用验证的假设，不声称有现成实验背书。

# 6. 反馈语言的红线（与 Math Learning Designer 对齐）

- 技巧必须数学上可靠：只有恒等式才写「一定」（如尾 5 平方）；启发式写法不含「一定」。
- 不使用「你怎么又错了」「这个很简单」；不显示错误次数；不羞辱。
- 记忆线索放在反馈，不放进做题过程；做题时安静。
- 声音永远可选；对错不只靠颜色。
- 不确定的教学效果标记为待复核（见第 5 节【经验】标注），不冒充研究结论。
