# 平台能力表

状态：跨端架构评审用。不是实施说明，也不改学习契约。

读法：H5 可以更丰富，核心和共用界面不能依赖 C 档。小程序必须能完成同一次训练。

档位：

- A：四端都能用同一套写法。
- B：能力相同，接口不同，必须走 `app/platform/`。
- C：只给某一端增强。没有时要有能完成学习的退路。
- 待核：小程序端还没验证。先走说明里的退路。待核不是已经兼容。

一行只有一个档。业务意图和平台动作拆开写。
