# Scientific Visual Language Contract

状态：`FROZEN FOR FIRST-LAUNCH BUILD`

本文件从首次上线实现起补充 `05_visual_system_v03.md`。冲突时，本文件只在吉祥物频率、反馈语气、知识地图和科学组件范围内优先；颜色令牌、主题替换、对错语义、打印和学习规则仍由旧合同控制。

## 1. 北极星

**温暖的数学实验室**。科学感来自观察、预测、推导、验证和关系，不来自霓虹、深色驾驶舱、公式墙或换一套颜色。

## 2. 共用科学组件

### `RelationChain`

显示节点、方向和关系；一节点时无悬空线；提供线性文本。

### `NumberLine`

显示刻度、零点、起点、方向和终点；必须支持负数和跨零；文本格式示例：`从 -7 向右移动 12，到 5`。

### `DecompositionSteps`

显示拆分、重组和结果；视觉顺序与 DOM 顺序一致。

### `FormulaTransform`

显示等式逐步变形；每步说明变形依据；最多 10 步时仍可读。

组件用 Taro `View`/`Text` 与 CSS 画线、刻度和箭头。不能依赖运行时 SVG 才能表达数学含义。

## 3. 动效

- 单次、短、可打断、不循环。
- 低动态直接显示最终状态。
- 动效不参与判题、掌握或是否能继续。
- 无动画、无图片、无声音时仍能完成全部流程。

## 4. 页面结构

- 首页：“今日训练”仍是唯一主操作；吉祥物最多一次。
- 专项：事实领域与七年级技能分区，不把技能伪装成第九个事实领域。
- 知识地图：显示层级、状态、前置、迁移和真实入口；mapped-only 无假按钮。
- 训练：题目和输入最大，不出现吉祥物或装饰性关系图。
- 正确/错误：关系和工具领先，去掉吉祥物。
- 结束：摘要克制，不用庆典海报。

## 5. 响应式

验收视口：

```text
320×568, 375×667, 390×844, 768×1024, 1366×768
```

H5 另验 200% 缩放。移动端地图为分层列表与局部关系链；宽屏在同一 DOM 上增强布局。底部导航、安全区、最长负分数题、三工具展开和提交按钮不得互相遮挡。

## 6. 触控、焦点、读屏

- 可点击目标最小 44×44 CSS px 等效面积。
- H5 可见焦点，顺序与阅读顺序一致，无键盘陷阱。
- 对错不只靠颜色。
- 符号、分数、循环小数、正负号、当前分数框都有可读文本。
- 连接线和装饰隐藏于读屏，关系文字不隐藏。

## 7. 主题边界

主题可换颜色、背景、角色、图标、装饰、动效、可选音效；不能替换题目、判题、掌握、调度、错题、打印、迁移或关系身份。科学组件只读语义数据，主题只决定表现。

## 9. 停止条件

- 视觉稿改变判题、掌握、调度或历史状态
- 数学含义只存在于图片/动画
- 低动态或缺图时不能继续
- 手机底栏遮挡学习内容
