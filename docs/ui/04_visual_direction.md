# 1. PT0 visual problem

UI0 把「克制、安静、不游戏化」落到了纸色底、墨色字、一颗深绿按钮。功能清楚，层次也稳，但视觉吸引力不够。

PT0 的真人反馈把这个问题说清楚了：界面能用，却太单调、太平、太像成人极简工具。Owner 自己不想继续练，因此也难以指望 12～15 岁的学生愿意回来。

这不是「把 CSS 调漂亮一点」。Calm（克制）滑成了 Bland（寡淡）。下一轮如果改原型，要先选定视觉方向，再动现有页面。

# 2. Owner evidence

Owner 原话要点：

> 功能挺好，但是界面太丑了，太单调了，连我都不想学下去了，别说孩子了。

据此记为：

`PT0 Owner Feedback → UI_CHANGE_REQUIRED`

# 3. Reference screenshot principles

Owner 提供的参考图偏小学、偏卡通，不能照搬版式、插画或素材。从中只抽出原则。

## What to learn

- 进页面就有吸引力，而不是先读完说明才知道这是什么。
- 颜色更丰富，但仍然有秩序。
- 模块之间有形状和节奏，不是同一张白卡重复三次。
- 有少量数学图形、符号或图标，让人记得住。
- 首页让人想点主按钮。
- 平方、常用乘积、分数到小数可以有各自的识别，但必须是同一套语言。
- 做对或练完时有一点喜悦，喜悦服务于「可以继续」或「可以停了」。

## What not to copy

- 幼儿园视觉、满屏糖果色、大量卡通人物。
- VIP、商城、奖励币、连胜、排行榜。
- 复杂底部 Tab、几十个入口。
- 游戏化盖过学习。
- 每张卡片像一个不同的 App。
- 版权版式和现成图形资产。

# 4. Target visual personality

旧关键词：Quiet / Paper / Calm。

本轮探索的关键词：

- Bright but Calm（明亮但克制）
- Teen-friendly（适合青少年，大约 12～15 岁）
- Math Lab（数学实验室）
- Playful, not childish（有趣但不幼稚）
- Modern educational（现代教育感，不是教务系统）
- Warm technology（轻科技，有温度）
- Visual curiosity（想点一下）
- 做题时仍然能专心
- Delight without gamification（有视觉奖励，没有重游戏化）

不要做成：幼儿园 App、考试系统、企业 SaaS、金融看板、通用 AI 落地页。

# 5. Three visual directions

流程和文案在三个方向里相同。变的是气氛、颜色、形状和主视觉。

## Option A — 澄蓝实验室

一句话：一间明亮的数学实验室，首页有几何光，做题时只留下数字。

- Mood：清、亮、轻科技。
- 年龄感：12～15 岁，偏初中实验室，不是小学教室。
- 颜色：浅青底 `#E5F4F3`，墨青字 `#102033`，主按钮 `#0C7C86`，暖沙高光 `#F3C15B`。
- 字体：Fraunces 做标题和题目，Sora 做界面。
- 形状：22px 圆角，主按钮全圆。立方线框是主视觉。
- 卡片：半透明白卡片，三个域同一结构。
- 图标：细线几何，无人。
- 首页：上方一块青绿主视觉，里面是立方线和 `15² / 225`，下面是「开始今天的练习」。
- 做题：大题目，白按键，提交是同一青绿。
- 做对：正确色和「对」，短停后下一题。
- 做错：冷色关系块，正确关系成为中心，「○ 看这里」，按钮「下一题」。
- 练完：一颗青绿与暖沙组成的光点，主按钮「先到这里」。
- 进度：短列表，沿用同一青绿小标，不做图表墙。
- 打印：暖白纸上的细线几何页眉，题目不是答案。
- 动作：线框可极慢漂，答错块一次进入，完成光点出现即停。
- 优点：最接近「数学实验室」，有记忆点，做题页仍能静下来。
- 风险：青绿色若再加更多渐变，会滑向通用科技落地页。主视觉只能留在首页。

候选令牌见 `design/option-a/DESIGN.md`。静态页在 `visual-exploration/option-a/`。

## Option B — 暖数方块

一句话：数字关系是一组可以碰的教具方块，暖、厚、清楚。

- Mood：温暖、有触感、轻快。
- 年龄感：12 岁出头也能接受；若方块再圆、颜色再甜，会偏小。
- 颜色：桃底 `#FFF1E4`，珊瑚按钮 `#E15A3A`，奶油 `#F6C453`，叶绿 `#1F7A62`。
- 字体：Plus Jakarta Sans，字重偏高。
- 形状：28px 圆角，按钮和按键带同色厚度。
- 卡片：横条方块，左边符号，右边域名。
- 图标：x²、×、¾ 三个粗几何符号。
- 首页：眉标「今天可以练一小段」，主按钮在三个方块之上，先邀请再选择。
- 做题：超粗题目。提交键用叶绿，和首页珊瑚分开。
- 做对：落到叶绿和「对」。
- 做错：更暖的厚度块托住正确关系，不发红。
- 练完：一块奶油方块，不是笑脸太阳。主按钮「先到这里」。
- 进度：三行方块的短列表，不出现奖杯。
- 打印：方块语言收成细边表格，避免彩色教具印糊。
- 动作：按下时厚度减少 2px。不弹跳，不撒花。
- 优点：最有「想按一下」的触感，三个域一眼能分。
- 风险：最容易被看成小学 App。必须守住无人、无商店、无金币。

候选令牌见 `design/option-b/DESIGN.md`。静态页在 `visual-exploration/option-b/`。

## Option C — 数感工作室

一句话：一本给青少年的数学刊物，靠巨大的字和一条热色被记住。

- Mood：干净、利落、有编辑气质。
- 年龄感：15 岁更合适；12 岁可能觉得冷。
- 颜色：暖纸 `#F4EFE6`，近黑 `#161616`，电光蓝 `#2436F2`，热橙 `#FF5A36`。
- 字体：Newsreader 做标题和题目，Sora 做界面。
- 形状：4px 圆角，细分割线，8px 色条。几乎无阴影。
- 卡片：不用卡片。三个域是三行列表。
- 图标：只用字符 x²、×、¾。
- 首页：竖排大标题「数感训练场」，深色矩形主按钮，下面是分割线列表。
- 做题：题目大到占上半屏，答案是一条底线。
- 做对：题目改为蓝色，加「对」。
- 做错：左侧热橙色条，大字写出正确关系。
- 练完：巨大的「练完了」和一颗星。主按钮「先到这里」。
- 进度：同一套分割线短列表。
- 打印：最接近最终纸页，页眉一条热色即可。
- 动作：几乎静止。颜色变化不超过约 200ms。
- 优点：最不容易幼稚，品牌识别靠字体就能成立，做题最专心。
- 风险：离「我想点」最远。若 Owner 的问题是寡淡，这个方向可能只是换了一种高级的寡淡。

候选令牌见 `design/option-c/DESIGN.md`。静态页在 `visual-exploration/option-c/`。

| 第一眼 | 有主视觉，想走进去 | 想按方块 | 先被大字挡住 |
| 12～15 岁 | 正中 | 偏年轻，仍可收住 | 偏年长 |

# 7. Role viewpoints

角色顺序是 Brand Guardian → Visual Storyteller → UI Designer → Whimsy Injector。Image Prompt Engineer 只提供图像语言，本轮不生成正式素材。下面是综合后的分工，不是互相覆盖。

## Brand Guardian

数感训练场在读到文字之前，应该像「可以动手的数学」，而不是「又一份作业」或「一个积分游戏」。品牌性格是明亮、清楚、有一点好奇。三个域可以有识别色或符号，但不可以变成三个品牌。年龄感锁在初中，拒绝幼儿化和成人后台。

## Visual Storyteller

首页要先讲一件事：今天有一小段实验或一小段练习，做完就能停。视觉母题用抽象数学物体：立方线、平方、乘号、分数条、数轴片段。人物不进画面。做题页把故事收起来，只留关系本身。答错时，故事从「你的答案」转到「这个关系长什么样」。

## UI Designer

层次只有三层：主行动、当前题目或当前关系、离开或查看进度。主按钮始终是开始或停下，不增加底部导航。键盘、答错块、结束页沿用同一令牌。对比度在实现前复核。短横屏必须让提交留在视口里。本轮只定义系统，不改 `prototype/`。

## Whimsy Injector

愉悦预算大约一成。允许：首页主视觉的慢速几何、按下时的轻微厚度、答对后的短停、练完时的一颗光点或一颗星。不允许：金币、连胜、排行榜、大声庆祝、幼儿笑声式文案。每一处趣味都要服务于「愿意再做一题」或「错了也不烦」。

## Image Prompt Engineer

若以后生成素材，提示词只描述抽象数学物体、柔和灯光、少量 3D、无人物、无文字水印、无奖励图标。三个方向的物体语言不同：A 是青绿空间里的线框立方，B 是暖色圆角教具块，C 默认不生成场景图。本轮不产出正式图片。

# 8. Open visual questions

Owner 看比较页时可以回答：

- 哪一个让我想点？
- 哪一个像 12～15 岁会留下来的东西？
- 哪一个有数学感，但不是学校作业？
- 哪一个有趣，但不可爱到幼稚？
- 哪一个在真正做题时仍然安静？
- 哪一个以后能认出是数感训练场？

尚未决定，因此也不写入 UI0 正文：

- 最终采用 A、B、C，还是 A 的首页加 C 的做题页这类混合。混合可以以后再提，本轮先看三个完整方向。
- 主视觉里的示例数字是否固定为 `15²`，或只是示意。
- 打印页是否跟随所选方向的颜色，或一律收成黑白细线。

# 9. DESIGN_RECOMMENDATION

`DESIGN_RECOMMENDATION`

建议先看 **Option A 澄蓝实验室**。

理由：它同时回答了这次的两个失败点。首页有主视觉和数学物体，不再是一张安静到没有性格的纸；做题页把装饰拿掉，专注还在。年龄感落在初中，比 B 不容易变幼，比 C 更想被点开。

若 A 的青绿让 Owner 觉得冷，B 是更暖的备选，但要接受「必须继续压住幼稚」这个成本。C 适合作为做题页的冷静参照，不建议单独作为整个产品的下一版长相，除非 Owner 认为吸引力已经够了、只是要更有气质。

这不是最终选择。Owner 选定后，才进入原型视觉改版。未选定前不改 `prototype/`，不合并 PR #6。

# 10. Cross-media Design Capability

这次补上的角色不只服务当前界面。以后按任务调用，不必每次七个角色一起上。

| 以后的东西 | 主要角色 |
| --- | --- |
| 产品界面 | UI Designer，教育产品再加 Brand Guardian 与 Whimsy Injector |
| HTML 教学页 | Brand Guardian + Visual Storyteller |
| PPT / 汇报页 | Brand Guardian + Visual Storyteller |
| 海报 | Brand Guardian + Visual Storyteller |
| 视频分镜 | Brand Guardian + Visual Storyteller + Image Prompt Engineer |
| 社交图片 | 同上，仍由 Image Prompt Engineer 写提示词，不在本轮出图 |

长期设计链可以记成：Product → UX → UI → Brand → Visual Storytelling → Delight → Prototype → Architecture。普通业务系统通常只需要 UX 和 UI。数感训练场这种面向学生的产品，需要 UX、UI、Brand 和 Whimsy。

本文件只记录这套能力。不在这里设计课件、海报或视频。
