# 1. Visual Personality

界面像一张安静的练习纸，不是游戏机，也不是挂墙数表。

学生打开后，第一眼应感到：地方是空的，字是清楚的，只有一件事可做。练习结束时有一点完成感，但完成标记不盖过「可以停了」。

视觉性格：

- **短。** 一屏里信息少。题目最大，说明最小。
- **稳。** 纸色底，深色数字，不闪、不跳、不倒计时。
- **可离开。** 主按钮在开始时邀请进入，在结束时邀请停下。
- **错了仍可看。** 答错时画面仍是同一张纸，正确关系成为新的视觉中心，而不是一张红屏。

不采用：霓虹、火焰连胜、金币堆、排行榜奖杯、满屏庆祝、书法标题、按颜色分族的数表海报。

# 2. Color System

颜色有名字。实现时用这些名字，不在各页另取相近色。

| 名称 | 值 | 用途 |
| --- | --- | --- |
| Paper | `#F6F3EC` | 所有屏幕的底 |
| Paper-raised | `#FFFDF8` | 答案框、列表行、预览纸 |
| Ink | `#1C2430` | 题目、答案、主标题 |
| Ink-soft | `#5C6670` | 说明、域标签、安静链接 |
| Line | `#E4DDD2` | 分隔、答案框默认边 |
| Action | `#1F4F45` | 唯一主按钮的底 |
| Action-ink | `#F6F3EC` | 主按钮上的字 |
| Correct | `#1E6B45` | 「对」的字与勾的颜色之一 |
| Notice | `#8A4B32` | 需要停下来看的小标记，不是报警 |
| Notice-paper | `#F3EBE3` | 答错时，正确关系所在区域的底 |
| Star | `#8D7344` | 结束页那一颗很小的星 |
| Focus | `#1C2430` | 键盘焦点环 |

规则：

- 主按钮的绿色只属于「现在最该做的那一个动作」。它不代表答对。
- 答对不全屏变绿。绿色只出现在「对」和勾上。
- 答错不用纯红，不用红色满屏，不用红色大叉当主角。`Notice` 只做一个小标记；主角仍是深色的正确关系。
- 对错同时有文字和形状。色盲或灰度下，勾和「对」、以及正确关系的句子仍然可读。
- 安静链接用 `Ink-soft`，不加按钮底。
- 打印预览和纸张不使用以上屏幕色。纸上是黑字白底，见第 12 节。

对比：正文 `Ink` 对 `Paper`，以及主按钮白字对 `Action`，都应达到正文级别的对比。`Ink-soft` 只用于辅助句，不用于题目和提交。

# 3. Typography

数字和中文都用清楚的无衬线，不用毛笔字，不用等宽字体当界面主字体。

推荐可免费获得的字体：

- 数字与拉丁：Source Sans 3，数字用表格数字，避免 `1` 和 `7` 挤在一起时跳动。
- 中文界面：Noto Sans SC。

若运行环境没有这两套字体，退到系统无衬线。不引入书法字体作为替代。

| 角色 | 手机 | 平板 / 电脑 | 字重 | 用途 |
| --- | --- | --- | --- | --- |
| Question | 40px | 64px | 560 | 题干 |
| Answer | 36px | 48px | 560 | 正在输入的答案 |
| Relation | 32px | 44px | 560 | 答错后的正确关系 |
| Title | 28px | 36px | 560 | 首页第一句、结束页第一句 |
| Body | 18px | 18px | 420 | 说明、结构提示 |
| Label | 14px | 14px | 560 | 域标签、安静链接 |
| Key | 28px | 28px | 560 | 屏幕数字键上的数字 |

题目行高约 1.2。说明行高约 1.5。题目和答案不斜体，不全大写。

一屏里最多三个字号层级：题目、说明、标签。结束页的「对了几题」用 Body，不升到 Question，避免变成分数海报。

# 4. Layout

所有页面一个纵列。电脑上这一列最宽 720px，居中。两侧是同一张 `Paper`，不放侧栏、不放图表。

间距只用这些：8、16、24、32、48。

- 屏幕边缘到内容：手机 16，平板和电脑 32。
- 题目到答案框：24。
- 主按钮与下一组内容：32。
- 安静链接之间：16。

形状：

- 主按钮高度 56，手机上宽度拉满内容列，圆角 12。
- 答案框高度 64，圆角 12，边 2px。
- 数字键最小可点区域 56×56，键与键之间 8。
- 卡片不用于把很多题排成网格。列表行只用一条底部分隔线。

高度：

- 默认没有阴影。答错时的关系区域只用 `Notice-paper` 和细边，不浮起来。
- 主按钮可以有按下时的颜色加深，没有弹跳。

层级永远是：

1. 这一页唯一的主按钮，或训练中的题目。
2. 答案或正确关系。
3. 一句说明。
4. 安静链接。

不把专项、进度、打印做成与主按钮一样大的三张卡。

# 5. Home UI

结构严格对应 UX，只规定长相。

从上到下：

1. 产品名「数感训练场」，用 Title，`Ink`。英文名不放在第一屏。
2. 一句说明，Body，`Ink-soft`：「把常会用到的数字关系，练到能直接想起来。」
3. 主按钮「开始今天的练习」。按钮内第一行是这五个字，第二行用 14px `Action-ink` 写「大约 5～10 分钟」。两行都在同一个按钮里，不在按钮外再做一条进度。
4. 三个专项名字排成一行或在窄屏上排成三行。每个名字是 Label 大小的文字按钮，无底色，高度至少 44。它们明显小于主按钮。
5. 三个安静链接：「最近练得怎么样」「错题本」「印到纸上」。`Ink-soft`，无底，上下留 16。三者同级，都不做成卡片或计数徽章。
6. 最底一句，Label：「练习记录只保存在当前设备，不会自动同步到其他设备。」颜色再弱一档也可以，但不要低于能读清。它不占主按钮的位置。不写浏览器、小程序或存储技术的名字。

今天已经练完：第一句改成「今天这段练完了」。主按钮文字改成「看看这次」，不再写 5～10 分钟。其下用安静链接写「再练一小段」，字号和颜色都弱于主按钮。

上次没做完：主按钮写「继续刚才的练习」。旁边或下方的文字链接写「重新开始一小段」。这仍是 UX 里待原型确认的方案；视觉只保证「继续」更大，「重新开始」更轻。不画未完成的红点。

没有图标墙，没有插画英雄区。

# 6. Training UI

训练屏没有顶部导航，没有底部标签。

从上到下：

1. 左上角文字按钮「先停一下」，Label，`Ink-soft`。它不是主按钮。
2. 域标签，Label，`Ink-soft`，例如「平方」。与题目隔 8。
3. 题目，Question，`Ink`，居左。这是屏幕上最大的字。
4. 答案框，Answer。空的时候框内没有占位例句，避免被当成答案。边是 `Line`。焦点或正在输入时边改为 `Ink`。
5. 需要时，答案框下一条 Body：「先写一个数。」分数还没写完时改为「先写一个分数」。值对但未约分时改为「2/4 和 1/2 一样大，再约到最简：1/2。」这类句子。颜色 `Ink-soft`，不是 `Notice` 的报警样式。分数在这句里用横线分数，不用斜线。
6. 接近结束时，域标签的位置改显示「快完成了」，仍是 Label，不出现进度条、百分比、剩余时间或倒计时环。

「再试一次」若保留，放在域标签同一位置，Label，`Ink-soft`。它不加大、不变色、不带叉。

手机上，题目、答案框和键盘尽量同时留在一屏。题目可以换行，但不被键盘挡住。

# 7. Keypad

屏幕键盘贴在内容列底部，底色仍是 `Paper`，顶上一条 `Line`。

键：

- 数字 `0–9`，三列。
- `0` 在最后一行中间。
- 删除在 `0` 的一侧，文字是「删除」，不只用一个图标。
- 提交在另一侧，或单独占答案框右侧之外的下一行整行。提交使用主按钮样式，文字「提交」。一屏里提交是训练时的主按钮。
- 只有普通小数题才出现小数点，放在 `0` 旁。整数题的这个位置留空，不放一个不能按的灰键。
- 只有分数题才出现「/」，占小数点的位置。整数题和普通小数题没有这个键。
- 循环小数题不加键。答案框本身写成 `0.( )`，数字进到括号里。框外不再放一个空答案框。
- 没有负号键。没有括号键。

键的底是 `Paper-raised`，字是 `Ink`，边是 `Line`。按下时底改为 `Line`，不闪绿、不闪红。

提交键在答案为空时仍然可按。按下后若为空，不播放错误动画，只出现「先写一个数」。

电脑上这份键盘仍然出现，但可以比手机更紧，键仍不小于 44×44。题目保持 Question 字号，不因为键盘变小而把题目缩成说明。

# 8. Correct Feedback

答对不换页面结构，不放彩纸，不放全屏勾。

答案框右边或框下出现：一个勾的形状，加上文字「对」。两者都用 `Correct`。勾的线框至少 2px，灰度下仍能看出是勾。

若声音开着，声音是短的，界面不依赖它。

这个状态停留很短，然后换下一题。停留时可以点「下一题」式的跳过；跳过用安静文字「继续」，不做成第二个同样大的主按钮。默认路径仍然是短暂停顿后自己进入下一题。具体时长建议 400ms 到 700ms。原型可以试这个范围，不改流程。

正确但慢：视觉与答对完全相同。不出现沙漏、不出现「慢」、不把勾改成别的颜色。

# 9. Incorrect Feedback

答错后输入锁住，键盘可以藏起或变为不可用，避免看起来还能改。提交键消失。

画面从上到下变成：

1. 「先停一下」仍在。
2. 原题目保留，但降为 Body，`Ink-soft`。学生仍能看见刚才问的是什么。
3. 一块 `Notice-paper` 区域，圆角 12，内边距 24。里面第一行是正确关系，用 Relation、`Ink`。这是这一屏最大的字。
4. 关系下方一句结构提示，Body，`Ink`。
5. 区域角落一个小标记：空心圆加上文字「看这里」。圆和字用 `Notice`。这是形状加文字，不是红色大叉。
6. 区域下方唯一主按钮：「下一题」。

不写「你错了」「又错了」「太慢了」。不显示错过次数。不在这题上提供「再答一次」。

第二次再错，视觉结构不变，不加重颜色，不放大标记。

# 10. Mastery UI

内部状态不出现在界面上。学生看到的话，以及它们的视觉：

| 学生看见 | 视觉 |
| --- | --- |
| 还没练到 | 通常不显示。若必须出现，只用 `Ink-soft` 的 Label |
| 正在熟悉 | Label，`Ink-soft`，无图标 |
| 已经很稳 | Label，`Ink`。可以在字前加一个小点，点用 `Correct`，同时仍有文字 |
| 再巩固一下 | Label，`Ink`。可以在字前加一个小空心圆，圆用 `Notice`，同时仍有文字 |

这些词不做成徽章墙，不配进度环，不配火焰。专项入口上的一句状态，用上面四句之一，Body 或 Label，放在域名字下面，颜色弱于主按钮。

不出现「动摇」「未掌握」「落后」。

# 11. Progress UI

一列，没有图表、没有坐标轴、没有连续天数的格子。

标题「最近练得怎么样」，Title。

然后是最近几次的列表。每一行：

- 左：日期，Body，`Ink`。
- 右：做完了，或先停了。Label，`Ink-soft`。先停了不用红色。
- 下一行：对了几题、做了几题。Body，`Ink`。不写百分号，不写「分」。

行与行之间一条 `Line`。

再下一块标题：「还要再见到」。下面每条关系用 Body 写出题目简称，右侧是「正在熟悉」或「再巩固一下」。没有「已经很稳」的长清单；若要提，只在列表上方一句「有一些已经很稳」。

空状态：Title 下写「还没有练习」，主按钮「开始今天的练习」。不画空图表。

页底安静链接「印到纸上」。

# 12. Session End UI

结束页垂直居中于内容列的上半部，不要做成奖状。

做完时：

1. 一颗星，16px，`Star`，在句子左侧或上方。只有一颗，不旋转、不连成一串。
2. 「练完了」，Title，`Ink`。
3. 「对了 8 题，做了 10 题」这种句子，Body。数字用表格数字。不出现百分制大号分数。
4. 若有更熟的关系：小标题「这几个更熟了」，然后最多三行关系名，Body。没有就不留空位。
5. 主按钮「先到这里」。
6. 安静链接「看看最近练得怎么样」。
7. 更弱的文字「再练一小段」，Label，`Ink-soft`，与主按钮距离 24，不能使用 `Action` 底。

先停时：没有星。第一句是「先停在这里了」。第二句「已经做的留下了」。主按钮仍是「先到这里」。不使用失败插画。

不出现秒数、名次、连续天数，也不出现「比前几天更顺」。

# 13. Print UI

屏幕上的打印流程仍用第 2 节的界面色。纸上的版式单独规定。

**屏幕**

- 标题「印到纸上」，Title。
- 说明一句，Body：「印的是现在还要再写的题。纸上没有答案。」从错题本进入时，这句改为：「印的是错题本里这些题。纸上没有答案。」纸面样式不变。
- 预览是一张 `Paper-raised` 的竖页，宽不超过内容列，比例接近 A4。里面只有题目列表，黑字，没有界面绿，没有星，没有正确率。
- 预览下唯一主按钮：「打印」。
- 域筛选若以后出现，用安静的文字选择，不做成彩色分族标签。
- 「答案单独印」若以后出现，是安静链接，不和题目预览放在同一张纸的预览里。
- 不能打印时，用 Body 显示：「这个环境完不成打印。」不提供换设备继续的按钮，不画二维码。

**纸**

- 白底黑字。题目用无衬线，约 18–22pt。
- 页眉只有日期和「今天可以在纸上再写的题」。没有分数，没有「错题」二字。
- 一题一行，行距足够手写。不排成彩色胶囊，不按域涂底色。
- 黑白打印必须能读。不靠颜色区分题目。

# 14. Responsive UI

任务和层级在三种宽度上相同。变化只在尺寸和键盘。

| | 手机 | 平板 | 电脑 |
| --- | --- | --- | --- |
| 列宽 | 铺满，边距 16 | 最宽 720，居中 | 最宽 720，居中 |
| 题目 | 40px | 64px | 64px |
| 键盘 | 固定在底部，键至少 56 | 同样固定，键可以到 64，但页面不改成多栏 | 键盘留在题目下方，键至少 44；物理键盘可不看它 |
| 主按钮 | 拉满列宽 | 拉满列宽，不超过 720 | 拉满列宽，不超过 720 |
| 导航 | 无底部标签 | 无底部标签 | 无底部标签 |

窗口窄于 720 时使用手机字号和边距。横屏时题目仍在键盘上方，提交仍可见；若高度不够，题目字号可以降到 32，不能让提交掉到屏幕外。

电脑上的焦点环：2px `Focus`，距控件 2px。鼠标悬停可以让安静链接出现下划线，但悬停不是发现按钮的条件。未悬停时链接已经是可读的文字。

# 15. Accessibility

- 题目与 `Paper` 的对比按正文要求。主按钮同样。
- 对错：勾加「对」；空心圆加「看这里」，再加完整的正确关系句子。
- 关闭声音后，上述文字和形状都还在。声音开关是进度页或首页底部的文字「声音开 / 声音关」，不是单独一个喇叭图标。
- 动画只有答对后的短停留。不用抖动表示错误，不用闪烁。停留可被「继续」跳过。
- 可点目标不小于 44×44。主按钮和数字键按第 7、14 节更大。
- 不只用颜色传达主按钮：主按钮有明确文字。
- 屏幕阅读的顺序与视觉顺序一致：先题目，再答案，再提交；答错时先正确关系，再提示，再「下一题」。

# 16. Motion

- 页面之间不做滑动故事转场。
- 答对：勾和「对」出现，400–700ms 后换题。
- 答错：关系区域直接出现，不从屏外砸入。
- 主按钮按下：颜色略深，100ms 内，不位移。
- 结束页的星不循环动画。

学生若开启系统的减少动态，答对改为立即显示「对」，然后仍按 UX 进入下一题，不保留装饰性等待。

# 17. What This Spec Does Not Change

以下保持 UX 与产品原文：

- 首页唯一主任务是开始今天的练习。
- 训练中一题一屏，无底部导航，无对照表，无倒计时。
- 答对短促前进；答错停住，看关系，按「下一题」，不能当场重答。
- 再出现不说「因为你错了」，不显示错误次数。
- 学生语言四句，不显示「动摇」。
- 结束以离开为主。默认没有「比前几天更顺」。
- 打印预览只有题目。当前环境不能打印时，不承诺换设备继续。
- 不登录，不排名，不诊断教程，不手写，不语音。

# 18. Open Questions

**可以留到原型看，不改流程**

1. 小屏横屏时，题目降到 32px 是否仍然一眼能读。`PROTOTYPE_DECISION_REQUIRED`
2. 答对停留 400–700ms，学生会觉得太赶还是太拖。`PROTOTYPE_DECISION_REQUIRED`
3. `Notice-paper` 与普通纸色的差别，在强光下是否还能感到「这里要看」，同时不像报警。`PROTOTYPE_DECISION_REQUIRED`

**继续保持上游未决，视觉不提前做成另一种模式**

- 5 分钟还是 10 分钟、题量、进度条形式：界面只使用「大约 5～10 分钟」和「快完成了」。
- 「再试一次」若原型证明像惩罚，删掉这四个字，不改其余视觉。
- 域筛选和单独答案页若不进入原型，打印屏就只有题目预览和「打印」。
- 全部已稳定时抽什么、小数写法是否等价、混用输入如何记录：都不是本文件要决定的。视觉不为此增加新组件。

**UX_CONFLICT**

无。

当前视觉都能套在已通过的流程上，没有要求改导航、反馈时序或产品边界。

# 19. UI Acceptance Criteria

1. 第一屏只有一个填色主按钮，文字是开始今天的练习，并带有大约 5～10 分钟。
2. 专项、进度、错题本、打印在视觉上明显弱于该按钮。
3. 训练屏最大字是题目；没有计时图形。
4. 数字键不小于规定的可点区域；整数题没有小数点和「/」；循环小数题没有新键；没有负号。
5. 答对能看见勾和「对」，屏幕其余部分仍是练习纸。
6. 答错能看见原题、正确关系、一句提示和「下一题」；没有红色满屏，没有大叉作为唯一标记。
7. 正确但慢与答对长得一样。
8. 结束页第一主按钮是离开；星只有一颗且很小；没有秒数和名次。
9. 进度页没有图表和打卡格；状态只用学生语言。
10. 打印预览是黑字题目；不能打印时只说明这个环境完不成，没有迁移入口。
11. 关掉声音、去掉颜色后，对错仍然能从文字和形状读出。
12. 手机、平板、电脑都是同一纵列，不是三套皮肤。
