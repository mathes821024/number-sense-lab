# 1. UX Goals

一个初中生第一次打开，到做完一小段，再到第二天回来，应当自然、短、没有被催促的感觉。

他不需要先学习这个产品。他需要能回答：

- 我现在就可以开始。
- 我知道这一题在问什么。
- 我能把答案输进去并改对。
- 对了我就过去；错了我能看见正确关系，并且还愿意做下一题。
- 我知道这一小段什么时候结束。
- 我能看出自己有没有更熟，而不是看出自己快不快。
- 手机和电脑是同一个练习，不是两套产品。

成功的体验不是页面多，而是：第一次开始够短；答错之后还愿意继续。

# 2. Design Principles

这些原则约束交互。视觉风格留给 UI。

1. **先做，后懂。** 不在开始前解释「数感」或「熟练度」。
2. **一条主路。** 今天最该做的只有一个主按钮。专项、记录、打印都让路。
3. **一题一屏。** 答题时没有对照表，没有第二题，没有计时。
4. **正确优先于快。** 慢不是一种失败反馈。学生看不到倒计时，也看不到秒数。
5. **错了是学习，不是处罚。** 错题会再出现，但再出现要像复习，不像追着罚。
6. **每节有终点。** 做完就可以停。不自动开始下一节。
7. **进步用自己的话说。** 不排名，不说「你退步了」，不把状态词变成评语。
8. **同一心智模型。** 手机、平板、电脑的任务相同。不同的只有手怎么输入。
9. **声音和颜色都不是唯一通道。** 关掉声音、或不靠颜色，仍然知道对错。
10. **纸上是当前要再写的题。** 打印不是一张答案海报。

# 3. Primary User Journey

## Journey A — First Visit

第一次打开不考试，不注册，不翻教程。

第一屏就是首页，只有三句他用得上的话：

- 这是什么：把常会用到的数字关系，练到能直接想起来。
- 现在做什么：一个主按钮，「开始今天的练习」。
- 要多久：大约 5～10 分钟。这里用的是产品已给出的时间窗，不把 5 或 10 收成一个数，也不写题量。

不解释四个内部状态。不介绍三个域的教学意义。三个专项可以在主按钮下面被看见，但不是第一眼要做的选择。

他按下主按钮，就进入第一题。产品在使用中被理解，不在说明里被理解。

设备上留一句安静的话，放在首页底部，不挡按钮：「练习记录只保存在当前设备，不会自动同步到其他设备。」

## Journey B — Daily Training

从首页主按钮进入。开始前不再插入确认页。时长预期已经在首页说过。不展示「今天重点」清单，避免一进门就像作业单。

然后是重复的一题：

1. 只出现一道题。
2. 学生输入，提交前可以改。
3. 提交后立刻判题。空答案不判错，停在这一题。
4. 对了：短反馈，接着下一题。可以出现吉祥物。不要求再点一次「下一题」才离开。「看知识点」若出现，点了只说「敬请期待」，不打开新流程。
5. 错了：留下看正确关系，学生自己按下「下一题」。不在原题上重答。不提供「再做一遍」。
6. 错过的关系隔开若干题后再出现。隔开几题仍按产品待验证问题，不在这里定数字。
7. 做题时可以看见轻进度，例如「2 / 10」，以及一条平静的进度。它不是倒计时，也不闪、不催。接近本节终点时，仍可以说「快完成了」。
8. 到达终点，进入结束页。

学生随时可以「先停一下」。已做的留下，这一次记为没做完，不叫失败。

## Journey C — Focused Practice

首页主按钮下方有三个平级的次级入口：平方、常用乘积、分数到小数。

点进去之前，用一句话说明这段也会结束：「只练这一块，同样是一小段，不是一直刷。」不展示该域全部题目。状态只用学生能懂的一句，例如「有几题要再巩固」，不说「你还有 37 个没掌握」。

进入之后，一题、输入、对错、结束，与今日训练相同。不同的只有题目来自一个域。

## Journey D — Error & Recovery

答错的瞬间：

- 输入锁住，不能在这一题上改完再提交。
- 不自动跳走。
- 画面的主角是正确关系，加上一句结构提示。
- 学生读完后按「下一题」。不提供「再答一次」。
- 不说「你错了」「太慢了」「又错了」。
- 不显示这道题错过几次。

再出现时，它就是一道新的一题，可以带一句很轻的「再试一次」。不说「这是你刚才错过的」。连续第二次仍错，反馈结构不变，不加重。

学生应感到：我看见答案了，我先继续；它等一下还会来，那是复习。

## Journey E — Session End

结束页先说这段结束了。

必须看见：

- 做完了，或「先停在这里了，已经做的留下了」。
- 这次对了几题、做了几题。这是正确率，但说成题数，不说成考分。
- 若有关系比上次更接近稳定：用「这几个更熟了」列出少量关系，用学生语言，不用内部状态词。

禁止看见：

- 秒、毫秒、倒计时残留。
- 排名、别人、连续打卡天数。
- 「你退步了」「你太慢了」。
- 原始词「动摇」。
- 「比前几天更顺」。产品尚未决定要不要这句话。默认不出现。

可以有一个很轻的完成标记，例如一颗星。它不打开下一节，也不能花掉。

下一步的主按钮是「先到这里」，回到首页。次级文字链接才是「看看最近练得怎么样」。不自动继续。可以有更弱的「再练一小段」，但不能比离开更显眼。

## Journey F — History / Progress

学生来这里是为了知道：最近有没有练，以及最近一次做这道题是对还是错。

页面有两块：

- 最近几次：日期、做完了或先停了、对了几题。没有图表墙，没有曲线。
- 最近练过的题：只列已经有作答记录的关系。每条显示关系本身，以及最近一次记下的结果：「对」或「错」。没有作答的题不出现在这里。

这一页不逐题展示「正在熟悉」或「再巩固一下」。掌握状态仍由系统保存，用来决定以后什么时候再练，也仍出现在专项入口的那一句概括里。

不展示反应时间。正确率下降时，只显示这次的题数，不解释为退步。页上有安静动作「选题打印」，进入和首页、错题本相同的选题页。

## Journey G — A4 Print

从进度页的「选题打印」，或错题本的「印这些题」进入。两条路进同一页，不各做一套打印。不放在首页主路径上。训练进行中不能进来。

先选题，再预览。说明：「选出要印的题。纸上没有答案。」

候选是已经练过的关系。还没练过的不铺成整表。当前错题默认勾上。当前错题仍是：曾经答错过，并且还没有重新变得很稳。最近一次答对、但还没很稳的，仍然默认勾上。其他练过的题默认不勾。

可以取消一道默认勾上的错题，也可以勾上另一道练过的题。可以按域看，也可以一次勾上当前错题或全部清空。勾选不改变掌握，也不改写错题本。最后只印勾上的题。

预览里只有题目。可以有日期。预览里不放正确率、不放「你错过了」、不放错过几次。

答案不进这张预览。若需要核对，必须另走一步「答案单独印」，并且文字说明等写完再看。两页不能在同一次预览里同时看见。

手机、平板和电脑走同一条预览。确认后，当前客户端按自己的能力提供打印、分享或保存。不另做一套桌面打印程序。系统自己的打印或分享窗口不是本产品的界面。

# 4. Information Architecture

普通页面有四个底部入口：首页、练习、错题本、我的。正在写答案时底部入口隐藏，只留这一题和「先停一下」。否则学生会在题和进度之间跳，段落就被拆掉。

| 地方 | 为什么存在 | 怎么进去 |
| --- | --- | --- |
| 首页 | 回答现在做什么、今天最该做什么 | 打开就是，底部「首页」 |
| 今日训练 | 主循环 | 首页「开始练习」 |
| 练习 | 选一个已有的域，或看见还没做的方向 | 底部「练习」，以及首页「专项练习」 |
| 进度 | 看最近有没有练，以及最近一次是对还是错 | 首页卡片，做完后也能到 |
| 错题本 | 看还要再写熟的错题，并可以现在就练 | 首页卡片，底部「错题本」 |
| 我的 | 声音开关还在；档案和清空记录还没有 | 底部「我的」。除声音外，点了说「敬请期待」 |
| 打印 | 自己选出要印的题，再带到纸上 | 进度和错题本进入同一页 |

专项不是题库目录。真正能练的仍是平方、常用乘积、分数到小数。图上的其他方向只显示「敬请期待」。

# 5. Home UX

首页必须同时回答：我可以做什么，今天最该做什么，大概多久。

**层级**

1. 产品名，和一句暖的话。可以有吉祥物。
2. 四张入口：开始练习、专项练习、错题本、最近练得怎么样。开始练习是今天的主路径，并让人知道大约 5～10 分钟。
3. 底部四个入口：首页、练习、错题本、我的。
4. 一句：练习记录只保存在当前设备，不会自动同步到其他设备。它不挡开始练习。

错题本里怎么练，见 `docs/ux/03_mistake_book_ux.md`。打印从进度和错题本进，不在首页再放一个入口。

**今天已经做完**

主区域改成「今天这段练完了」，主按钮变成「看看这次」，去刚结束的那一页。仍允许再练，但「再练一小段」是次级，不催。没有打卡、没有「你断了」。

**上次没做完**

这是原型前要确认的行为，见第 18 节。当前建议：主按钮写成「继续刚才的练习」；旁边用文字提供「重新开始一小段」。不责问为什么离开。

**第一次，以及全部都很稳**

第一次按上面的默认首页。若当前没有不稳定关系，不把首页变成空白。主按钮仍可开始一小段；这段里抽到什么，产品队列还没定义，见第 18 节，UX 不另起一种模式。

# 6. Daily Training Flow

1. 首页按下主按钮。
2. 直接第一题。没有准备页，没有诊断。
3. 作答、反馈，循环到终点或学生先停。
4. 结束页。
5. 「先到这里」回首页。

开始前不列今天要练的清单。学生要的是开始，不是预习目录。

先停一下时，先问一句：「先停在这里？已经做的会留下。」两个选择：「继续做」和「先停」。没有「放弃」这个词。

# 7. Focused Practice Flow

1. 在首页点一个域的名字。
2. 看到一句：「只练这一块，同样会结束。」以及一句很短的状态，用学生语言。
3. 按钮：「开始这一小段」。
4. 其后与今日训练相同，包括先停、结束页、不再自动续上。

状态句只用四档学生语言里的一档概括这个域，不列出全部关系：

- 还没怎么练
- 正在熟悉
- 有几题要再巩固
- 大多已经很稳

这样专项不会被理解成无限题库：入口就说它会结束，结束页也一样让人离开。

**题目不要露出机械顺序**

选题可以有学习上的先后。学生连续看到的题，不应让人靠上一题猜出下一题。

不要连续按大小往上或往下排，也不要把同一族排成串，例如 `6×2`、`6×3`、`6×4`。今日训练继续三个域交错。专项虽然只有一块，也要打散，不能变成按口诀表往下背。错题练习里，已经轮到的仍先于还没轮到的；同一档里面不要排成数字表。

界面不解释这套顺序，不显示「随机」「第几号规律」或下一题预告。学生只看到当前这一题。

# 8. Question Interaction Model

## Question Area

- 一次只有一题。题干是这一屏的视觉中心。
- 可以有一个很小的域标签：平方、常用乘积，或分数到小数。它帮助分辨题型，不是一节课的标题。
- 不显示倒计时、秒表、百分比、剩余时间。
- 不显示对照表，不显示这道题的历史对错次数。
- 可以显示本节位置，例如「2 / 10」，加一条不催促的进度。临近结束时仍可以说「快完成了」。
- 一步应用若以后进入，仍是一题一屏、同一种输入。第一版交互按直接提取来设计。

## Answer Area

一个答案框。提交前随时可改。判成对或错之后锁住，直到这一题的反馈结束。值对但还没约成最简时不锁死，学生改完可以再交。

v0.1 不提供负号。三个域的直接提取答案都不是负数。

整数题不放小数点，避免误触。分数到小数、且答案是普通小数的题才出现小数点。第二个小数点按不进去，不把这题判错。

答案是分数时，键盘是数字、「/」、删除、提交，没有小数点。学生输入分子/分母，例如 `1/8`。分子和分母都有了以后，答案框改用横线分数显示。其他题型不出现「/」；物理键盘上的斜线在那些题里按不进去。

答案是循环小数时，学生仍然只输入循环节，例如 1/3 输入 `3`，1/7 输入 `142857`。没有循环点键，也没有括号键，不要求把循环节再打一遍。屏幕上不出现 `0.(6)` 这种括号。一位循环时，点标在这个数字上方；多位循环时，点标在循环节第一位和最后一位的上方。这些点由共享的数学渲染画出来，不用组合字符硬凑。存下来和判对错仍用 `0.(6)`、`0.(142857)`，学生看不见这套括号。读屏时要能读出「0.6，6 循环」，不能只靠那个点。

只按了小数点、什么都没写、循环节还是空的，或分数还没同时写上分子和分母就提交：停在这一题，提示「先写一个数」或「先写一个分数」。这不是一次错误，不进入错题，不改变熟练状态。

前导 0 允许出现在输入过程里。`0289` 算不算 `289`，`0.50` 算不算 `0.5`，是答案判定，不是本规格要定的规则，见第 18 节。

**手机和平板**

屏幕数字键盘固定在题的下方，尽量和题目、提交同时留在一屏里，不靠滚动去找提交。键包括：数字、删除、提交。普通小数题加小数点。分数题把小数点换成「/」。循环小数题不加新键。键要大，能单手或双手点。

在数字键上快速连点，必须记成按键，不能被浏览器当成双击把页面放大。不要因此关掉整页的双指缩放。若某一端连点仍会放大，只限制键盘这一块，不全页拦截触摸。

**电脑**

物理键盘可以直接打数字。Enter 提交，Backspace 删除。这是便利，不是必须知识。屏幕上仍有可点击的数字键盘和提交按钮，只点也能做完。不需要悬停才看见按钮。

同一题里允许键盘和点击混用，学生只看见一个答案框。这次作答算哪种 `input_mode`，见第 18 节。学生界面不解释输入方式。

连续快速点提交：只接受第一次。反馈没结束前，不再判第二次。

# 9. Correct / Incorrect Feedback

| 情境 | 学生看见什么 | 然后 |
| --- | --- | --- |
| 正确 | 一个短的「对」，加上不是只靠颜色的标记。声音若开着，很轻 | 短暂停顿后进入下一题。这段可以跳过 |
| 正确但比往常慢 | 与「对」完全相同。不出现「慢」「再快一点」 | 与正确相同。慢只留给系统内部，可能影响以后抽题，不降级 |
| 不正确 | 主角是正确关系，加一句结构提示。标题不是「你错了」 | 停住。学生按「下一题」才离开。不能在这题重答 |
| 值对，还没约成最简 | 「2/4 和 1/2 一样大，再约到最简：1/2。」其他题换成刚才写的分数和最简分数。不说「你错了」 | 留在当前题，答案框可改。改成最简后再提交。不进入下一题 |
| 再出现 | 普通一题。最多一句「再试一次」 | 按新的一题作答 |
| 本节做完 | 结束页，完成标记可以很轻 | 主路是离开 |
| 中途停下 | 「先停在这里了，已经做的留下了」 | 不叫失败，不显示未做完的惩罚 |
| 还没有记录 | 进度页说明还没练过，并把人送回开始 | 不显示空图表 |
| 还没有练过的题 | 说明先练一小段，之后才能选题打印 | 不生成整域海报来填空 |

不正确的反馈必须能学：看见关系本身，看见一句为什么。红叉不能单独存在。不使用满屏失败、闪烁或羞辱。

正确的自动进入下一题要短。不正确绝不自动跳，否则学生来不及看。

# 10. Error Reappearance

再出现是复习。

- 错题反馈结束后，下一题是别的关系，不是刚错的这一题。
- 隔开的题数不在本规格里定死。
- 再出现时不说「因为你错了」。历史错误次数不出现。
- 「再试一次」可以有，但若原型里学生觉得被追着罚，就拿掉，只留普通出题。
- 同一节里不反复磨同一题。第二次仍错，提示不升级成批评。
- 以后的今日训练和专项里，它会优先再见到。学生不需要知道排序公式。

# 11. Session Completion

终点必须被看出来，而且是停，不是通向下一段的门。

做完时：

- 第一句是练完了。
- 第二句是对了几题、做了几题。
- 若有，第三句是「这几个更熟了」，只列少数，不列全部未掌握。
- 一颗很轻的完成标记可以在，不占据主信息。
- 主按钮离开。次级才是看进度或再练。

没做完时：

- 不出现失败色块和「未完成任务」。
- 明确已经做的还在。
- 同样以离开为主，不催马上补完。

「比前几天更顺」默认不放。放与不放回到产品待验证问题。

# 12. Progress & Mastery UX

内部状态不改。学生界面不直接使用「未练 / 学习中 / 稳定 / 动摇」，尤其不使用「动摇」。

| 内部状态 | 学生看见的话 | 哪里可以看见 |
| --- | --- | --- |
| 未练 | 还没练到 | 通常不列出来 |
| 学习中 | 正在熟悉 | 专项入口的一句概括。进度页的逐题列表不使用这句 |
| 稳定 | 已经很稳 | 结束页的「更熟了」；专项入口的一句概括 |
| 动摇 | 再巩固一下 | 专项入口的一句概括。意思是还要再见到，不是退步判决。进度页的逐题列表不使用这句 |

结束页和进度页不展示反应时间。不展示跨天的速度比较。正确率只用「对了几题 / 做了几题」，避免变成一个人的分数人格。

最近几次就是一张短列表：日期、做完或先停、对了几题。不做图表墙，不做连续打卡，不做 streak。

没有历史时，这一页说「还没有练习」，并给出回到开始的路。

# 13. A4 Print UX

路径：入口 → 知道内容是什么 → 预览 → 当前客户端按能力提供打印、分享或保存。

**入口**

进度页「选题打印」、错题本「印这些题」，进入同一选题页。训练进行中不能打印，避免边看答案边做题。

**范围**

先列出已经练过的关系。还没练过的不进入候选。当前错题默认勾选。其余练过的题默认不勾。当前错题的定义与错题本相同，不改成「最近一次答错」。

学生可以改勾选。按域筛选只是缩小眼前的列表。纸上只出现最后勾上的题。改勾选不改掌握，也不改错题本里的记录。

从错题本进来时，仍是这一页。当前错题先出现在眼前，并且已经勾上。其他已经练过的关系仍可查看并勾选。不是另一套纸。

**预览**

- 只有题目。
- 可以有日期。
- 没有正确率，没有学生排名，没有「错题」字样。
- 黑白也能读。不依赖颜色区分题目。
- 题目多时可以跨页，但仍然是这一次的复习，不是三个域的海报。

**答案**

默认预览里没有答案。另一步「答案单独一页」若保留，必须单独预览、再按当前客户端交付，并写明写完再看。两页不同时出现在一个预览里。这一步是否进入第一版原型，见第 18 节。

**没有可印内容**

说明原因，并回到开始练习。不改去印全部关系。

**手机**

预览在手机、平板和电脑上相同。确认后，当前客户端按自己的能力提供打印、分享或保存。若当前客户端做不到这些，就明确告诉学生：这个环境完不成把题目带出去。v0.1 不承诺换一台设备后，还能继续拿到同一批当前关系。不因此增加云同步、导出迁移、二维码转移、登录或后端。

# 14. First-time Experience

打开 → 一句说明 → 大约 5～10 分钟 → 开始今天的练习 → 第一题。

不做多页教程，不做诊断，不要求看完三个域的介绍。专项在首页可见，但第一路径不强迫选择。

第一次的结束页用同样的结构。若还没有任何「更熟了」，就不写这句，只写对了几题。不编造进步。

# 15. Cross-device UX

必须相同的：

- 首页的主任务和信息层级。
- 一题一屏、提交前可改、提交后判题。
- 对了短反馈并前进；错了留下看关系，再自己进入下一题。
- 没有倒计时和原始时间。
- 结束页的信息和离开为主的下一步。
- 进度和打印的任务。
- 先停会留下已做的。
- 不依赖悬停、右键或快捷键才能做完。

可以不同的：

| | 手机 | 平板 | 电脑 |
| --- | --- | --- | --- |
| 输入 | 屏幕数字键盘，大键 | 仍是触屏键盘，不改成桌面密度 | 物理键盘优先，点击键盘仍在 |
| 布局 | 题和键盘尽量一屏，少滚动 | 空间可以更松，键盘不缩成一条细栏 | 题仍然是中心，键盘是辅助 |
| 带出去 | 预览后，按当前客户端打印、分享或保存 | 同手机 | 预览后，按当前客户端打印、分享或保存。浏览器打印只是 H5 / PC 的一种做法 |

横屏手机仍要同时够到题目和提交。窗口很窄时用手机这一套，不把桌面布局挤扁。

完成一节不需要快捷键。Enter 和 Backspace 只是电脑上的加速。

# 16. Accessibility & Usability

原则，不是视觉规范：

- 题目的字要明显大于辅助说明。具体字号由 UI 定。
- 提交、数字、下一题的可点区域要大。具体像素由 UI 定。
- 对错同时用文字和形状，不只用颜色。
- 声音关掉后，对错、正确关系、结束信息都还在。
- 动画短，并能跳过。不播强烈失败动画。
- 键盘可以完成电脑上的输入和提交。只点击也可以。
- 不依赖悬停。
- 一屏里的决定尽量少：训练中就是写答案或下一题。
- 不使用只靠记忆才能懂的图标。域的名字用文字。

# 17. Edge Cases

| 情况 | 期望体验 |
| --- | --- |
| 第一次打开，没有历史 | 直接可开始。进度页说明还没练过。打印说明还没有要印的题 |
| 当前关系都已稳定 | 首页不变成错误或空白。能否开练见第 18 节，UX 不新造一种模式 |
| 还没有练过、或一题都没勾 | 说明，并回到开始。不改印全部未练的题 |
| 做到一半关掉页面 | 已提交的作答留下。未提交的输入不判错 |
| 再次打开 | 建议能继续刚才那段，也能重新开始。见第 18 节 |
| 本机数据被清除 | 看起来像第一次。底部那句记录位置仍然在 |
| 手机横屏 | 题和提交仍同时够到 |
| 窗口很窄 | 使用手机布局 |
| 连续快速提交 | 只判第一次 |
| 空答案 | 不判错，停在这一题 |
| 只输入小数点，或试图输入第二个小数点 | 不判错。第二个点不进入答案 |
| 页面刷新 | 若这题还没提交，刷新后仍是这题，不记一次错误。已提交的反馈若还没看完，仍能看到正确关系，而不是被跳过 |
| 音效关闭 | 信息完整，位置在首页或进度的安静设置里，不放进答题主流程 |
| 键盘和点击混用 | 允许。学生无感知 |
| 同一节里从键盘改成点击 | 允许。这一次的时间不向学生解释成变慢或变快 |

音效开关记住在本机。默认可以有轻声，但第一次不弹出声音权限说明来挡住开始。若当前环境不播放声音，训练照常进行。

# 18. UX Open Questions

下列问题本规格不冻住。

**PRODUCT_DECISION_REQUIRED**

这些问题回到产品层。UX 不改 PRD。

1. 所有当前关系都已稳定时，今日训练抽什么？产品队列是按尚未稳定的关系定义的。建议：不要死路，可以有一段很短的再确认，但那已经是产品规则，不是交互能私自加的题库。
2. 结束页是否出现「比前几天更顺」。本规格默认不出现。
3. `0289` 与 `289`、`0.50` 与 `0.5`、`.5` 与 `0.5` 是否都算对。输入允许学生这么打；算不算对要产品规定。在规定前，原型不要把这些判成羞辱性的错。
4. 同一题混用物理键盘和屏幕键盘时，`input_mode` 记哪一个。产品只定义了两种。建议：纯键盘与纯点击必须能分开；混用的这一次不要拿去和另一种方式比时间。具体记法留给后续设计。
5. 一节是更接近 5 分钟还是 10 分钟，以及做多少题。首页只说「大约 5～10 分钟」。
6. 首次是否诊断。本规格不设诊断。
7. 错题隔开几题、一节最多再出现几次。
8. 多慢算慢。学生界面不感知慢。
9. 一步应用是否进入第一批。交互先按直接提取。若进入，仍是一题一屏，不改输入模型。
10. 小数 → 最简分数、循环小数的输入，已经写进第 8 节和第 9 节。不再作为开放问题。

**PROTOTYPE_DECISION_REQUIRED**

这些要在原型里看真人反应，再冻住交互。

1. 没做完再打开：主按钮是「继续刚才的练习」，同时给「重新开始一小段」。要看学生会不会觉得被抓回去补作业。
2. 训练中的进度已经决定：用「2 / 10」这种轻进度，可以有一条平静的进度。不用百分比，不用剩余时间，不倒计时，不催。接近终点时仍可以说「快完成了」。
3. 再出现时那句「再试一次」是帮助，还是惩罚感。若像惩罚，就删掉。
4. 打印的域筛选，以及「答案单独一页」，是否放进第一版原型。默认路径不依赖它们：只预览题目，再由当前客户端打印、分享或保存。
5. 「大约 5～10 分钟」是否足够让学生愿意按下开始。

**PRODUCT_CONFLICT**

无。

没有发现必须改产品原则才能落地的冲突。上面的空档是未定义，不是两条产品规则互相打架。

# 19. UX Acceptance Criteria

后续 UI 和原型可以用这些判断，不看视觉好不好看。

1. 第一次打开，不经过教程和诊断，就能从主按钮进入第一题。
2. 首页能看出：主任务是今天的练习，大约 5～10 分钟。
3. 三个专项找得到，但不会和主按钮同等抢眼。
4. 训练是一题一屏，能输入、修改、提交。
5. 手机上不需要放大页面才能完成一题。
6. 电脑上只靠键盘能做完，只靠点击也能做完。
7. 答对会离开；答错会留下正确关系和一句提示，不会只剩一个叉。
8. 答错后不能在同一题立刻重答，下一题也不是刚错的那一题。
9. 再出现不像处罚：没有错误次数，没有「你又错了」。
10. 没有倒计时，学生也看不到秒数。
11. 正确但慢时，学生看到的仍是普通的「对」。
12. 本节有终点。结束页以离开为主，不自动开始下一节。
13. 结束页有对了几题、做了几题；没有排名和原始反应时间。
14. 学生能在进度里看懂最近几次，以及最近练过的题是对还是错，而不看到「动摇」。
15. 学生能找到打印，并在打印前知道纸上是题目、没有答案。
16. 关掉声音后，对错和结束信息仍然完整。
17. 对错不只靠颜色。
18. 先停不会被说成失败，已提交的作答还在。
19. 空答案不会被记成一次做错。
20. 手机、平板、电脑的任务一致。训练中不依赖悬停和快捷键。

# 20. Handoff Notes for UI Designer

UI 可以决定：

- 视觉风格、色彩、字体。
- 卡片、图标、完成标记长什么样。
- 动效的具体表现，只要短、可跳过、失败不变成惊吓。
- 视觉层级的具体尺寸，只要首页主按钮仍然是唯一主行动，题目仍然是训练屏的中心。

UI 不能改变：

- 首页、训练、专项、进度、打印的关系。
- 主流程和反馈时序：对了可以短促前进，错了必须停下来看关系。
- 学生语言与内部状态的对应。不得把「动摇」直接印到界面上。
- 不展示倒计时和原始反应时间。
- 打印预览不把题目和答案放在同一眼。
- 产品边界：不登录、不排名、不诊断教程、不做手写和语音。

对比度、字号和按钮尺寸按第 16 节的原则落实，但不要在 UI 稿里改流程来迁就装饰。

# 21. Handoff Notes for Prototype Designer

原型是给人试用的表面，不是最终代码。它要回答的是「真能用」，尤其是这两件：

- 第一次打开，会不会很快按下开始。
- 答错之后，还愿不愿意做下一题。

请让人能走完这些：

- 首次进入是否一眼看懂，而不需要说明。
- 今日训练是否容易开始。
- 手机数字键盘是否顺手，小数点会不会误触。
- 电脑键盘是否顺手，只点键盘是否也能做完。
- 错误反馈是否愿意看完，还是想立刻关掉。
- 再出现是否有被罚的感觉。
- 不知道精确题量时，「大约 5～10 分钟」和结尾的「快完成了」够不够。
- 结束页是否觉得可以停，而不是被拽去再练。
- 进度页是否看得懂，会不会紧张。
- 打印入口是否找得到，预览是否会被当成答案表。

原型可以先不做：诊断、速度句子、域筛选、单独答案页、一步应用。这些还没冻住。

试用时看行为，不看视觉完成度。
