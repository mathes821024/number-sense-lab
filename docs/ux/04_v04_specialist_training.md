# v0.4 专项入口

状态：契约设计，供 Contract Gate。流程仍是 `docs/ux/02_ux_spec.md`：开始练习是主路径，做题时底部入口隐藏，答对短暂停顿，答错停在正确关系上再按「下一题」。

# 1. 卡放在哪里

新卡放在「练习」里的专项列表，不放进首页主按钮的位置。首页仍然是四张入口，开始练习最大。

一张卡对应一个 `domain_id`。点开之后只抽这个域，结束和反馈与今日训练相同。

# 2. 卡片

| 卡片文字 | domain_id | v0.4 |
| --- | --- | --- |
| 平方 | `squares` | 保持打开，不改名 |
| 常用乘积 | `products` | 保持打开，不改名 |
| 分数到小数 | `fraction_decimal` | 保持打开，不改名 |
| 立方 | `cubes` | 该域文件发布后打开 |
| 半数与翻倍 | `halves` | 该域文件发布后打开。这张卡取代「倍数与因数」占位 |
| 补数 | `complements` | 该域文件发布后打开 |
| 常见幂 | `powers` | 独立卡片。该域文件发布后打开 |
| 凑整乘积家族 | `special_products` | 独立卡片。该域文件发布后打开 |
| 规律探索 | 无 | 继续「敬请期待」 |
| 概念 / 例题 / 动画 | 无 | 继续「敬请期待」。不是训练域 |

未发布的新域，卡可以出现，点了仍是「敬请期待」，不进入空专项。已发布的域不再显示「敬请期待」。

# 3. 做题时看见什么

域标签用上表的中文名。补数题干是「37 和几凑成 100？」这种凑成句，不是减法等式。半数题干是「86 的一半是？」。立方和幂用上标，乘积用 `25 × 4 = ?` 这种已有写法。

答案仍是现有整数键盘。不为新域加小数点、分数线或新键。

答错时主角仍是正确关系，加一句钩子。策略型的钩子讲的是拆半或凑整，不是「把这一对背下来」。相关例可以出现，但不新开一页课。

# 4. 错题本分组

已发布的域若有当前错题，就有一组，标题用卡片文字。某一组没有当前错题时，不留空标题。组内仍不按错次排。

`docs/ux/03_mistake_book_ux.md` 里的「三组」描述的是当时只有三个域。域变多之后，分组规则仍是「按域分组、空组不显示」，组数跟着已发布的域走。
