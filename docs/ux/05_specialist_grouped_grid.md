# 1. 信息架构

这一页只回答：我今天想专项练哪一种数感关系？

「主题训练」和「知识地图」是两个入口，不是同一组卡片。

```text
探索数学世界
├─ 主题训练
│   └─ 八个专项训练域（下面的分组双列）
└─ 知识地图
    └─ 以后的初中数学知识图谱
        概念、关系、例题、动画、以及从那里去训练
```

知识地图不是八个训练域中的一个，也不放进这八张卡。概念、例题、动画、规律探索属于以后的知识地图，不作为练习页上的「敬请期待」卡。

这一轮不实现知识地图。顶部切换保留。「知识地图」点了只说「敬请期待」，不把八张训练卡再画一遍。

页头：

```text
探索数学世界
从一个主题开始，走更远的路

[ 主题训练 ]  [ 知识地图 ]
```

「主题训练」是当前选中项。首页的开始练习仍是每天的主路径。这一页从底部「练习」或首页「专项练习」进入。

「今天想练哪个？」若出现，只是页头的辅助小字，弱于下面的分组标题。它不是一段的标题。

C 方案里的「上次练的」不放在这一页。最近练了什么仍在进度页。

# 2. 分组双列

手机竖屏是两列卡片，上面有很轻的分组标题。不是一列长列表，也不是八张完全平权的应用图标。

分组是导航，不是正式的数学知识图谱。以后的知识地图可以有更严的结构。这一页的组可以再调整，不因此改 `domain_id` 或调度顺序。

| 导航组 | 卡片 | 浅辅助色 |
| --- | --- | --- |
| 幂与乘方 | 平方、立方、常见幂 | 蓝 |
| 乘法与凑整 | 常用乘积、凑整乘积家族 | 暖橙 |
| 数与分数 | 分数到小数、半数与翻倍、补数 | 薄荷绿 |

组内顺序就是上表从左到右、再下一行。一组有三张时，第三张留在左列，右列空着，卡片不拉成通栏。

# 3. 卡片

一张卡只有三样东西：图标、域名、一句状态。不加 B 方案里的「如 13²」说明。

```text
┌────────────────┐
│   [图标]        │
│   平方          │
│   大多已经很稳   │
└────────────────┘
```

状态是弱标签，放在名字下面，不是第二主角。只用已有的四句：

- 还没怎么练
- 正在熟悉
- 有几题要再巩固
- 大多已经很稳

未发布的域仍可以出现这张卡，点了是「敬请期待」，不进入空专项。已发布的域不再显示「敬请期待」。

点一张已发布的卡，之后的流程仍是 `docs/ux/04_v04_specialist_training.md`：只抽这个域，结束和反馈与今日训练相同。

# 4. 为什么这样分组

幂与乘方放在一起，是因为平方、立方、常见幂是同一类运算，孩子能看出它们有关。

乘法与凑整放在一起，是因为常用乘积和凑整乘积都是乘法关系。以后的 25 系、125 系、拆分乘法、乘法速算，若成为新的训练域，归进这一组，不新开一种页面。

数与分数这一组是现在的导航，不是永久分类。分数到小数、半数与翻倍、补数都在「数本身怎么变」。以后可以再拆，不在这一轮做成知识图谱。

八张卡仍然各自对应一个 `domain_id`。分组标题不是 domain，不进调度，也不进错题本分组。错题本仍按域分组。

# 5. 图标语义

每个域一个固定符号，做记忆锚点。平方不用立方体。立方才用立方体。

| 域 | 符号 | 不用 |
| --- | --- | --- |
| 平方 | 正方形，或 2×2 方格 | 立方体 |
| 立方 | 立方体 | 与平方共用同一枚 |
| 常见幂 | xⁿ | 再画一个立方体 |
| 常用乘积 | 点阵 | |
| 凑整乘积家族 | 拼在一起的块，或 25×4 的分组 | 与常用乘积同一枚点阵 |
| 半数与翻倍 | 两个相连的圆，或 ×2 / ÷2 | |
| 补数 | 补满的环，指向 100 | |
| 分数到小数 | 1/2 与 0.5 的对应 | 斜线分数作为图标主角；1/2 用横线分数 |

图标文件和槽位以 `docs/ui/08_fb_specialist_visual.md` 为准。H5 和微信读同一套透明 PNG。不把内联 SVG 当作来源。常见幂和补数的现稿可以先用，以后只换文件。

# 6. 以后变多

布局按「还会增加」来做，不只为正好八张。

域从 8 增到 12、16 时，仍是同一页：分组标题加两列卡片。新域进入已有组，或增加一个新的轻标题。不改成一列长列表，也不为了塞进一屏把卡片缩到不可点。

一屏放不下时可以滚动。分组标题跟着内容走，不钉死成第二套导航。

# 7. 视觉

沿用现有品牌：奶油纸底、青绿主色、圆角，适合约 12～15 岁。有孩子气，但不是幼儿园，也不是彩虹玩具。

卡片底仍是 `color.surface.card`。家族色只出现在图标底的一层很浅的颜色：

| 组 | 用已有令牌 | 不用 |
| --- | --- | --- |
| 幂与乘方 | `color.accent.sky` 的浅底 | 把整张卡涂蓝 |
| 乘法与凑整 | `color.accent.amber` 的浅底 | 把暖橙当成警告 |
| 数与分数 | `color.brand.secondary` 的浅底 | 另起一套薄荷绿品牌色 |

主按钮仍只有青绿。状态标签用 `color.text.secondary`，不靠颜色单独表达掌握。

# 8. H5 与小程序

H5 和微信是同一页结构、同一分组、同一卡片内容、同一资产槽。不各做一套练习目录。

底部四个入口不变。正在写答案时底部入口仍然隐藏。这一页不是做题屏，底部入口留着。

# 9. 无障碍

- 分组标题是标题，不只靠颜色。
- 一张卡是一个按钮。读屏读出域名和那句状态，例如「平方，大多已经很稳」。
- 状态不只靠颜色。四句文字都在。
- 可点区域不小于 44×44。卡片本身就是可点区域，不另做一枚小箭头当唯一目标。
- 浅辅助色叠在奶油卡片上时，图标和名字仍用 `color.text.primary`，对比按正文要求。
- 关掉颜色之后，分组标题和卡片文字仍然能读出结构。
