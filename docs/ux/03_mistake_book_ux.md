# 错题本交互

状态：待审阅。本文不是已冻结契约。通过审阅并 Freeze 之前，不实现。

本文只描述错题本这一条路径。今日训练、进度、打印选题，以及答错后停住、隔题再现，都保持已有学习规则。首页怎么进到这里，见 `docs/ux/02_ux_spec.md`。

# 1. 入口

错题本只有一个学生入口。

首页有一张「错题本」卡片，底部也有「错题本」。它不写成错过的次数，也不做红点。开始练习仍是今天的主路径。

进度页回答的是最近一次做对还是做错，不代替错题本。从未答错过的题可以出现在进度里，并标成最近答对。那不是当前错题。

训练进行中仍然没有底部导航，不能从题目页跳进错题本。

# 2. 错题本页

打开后只有一块当前列表。

标题是「错题本」。下面一句：「这里是还要再写熟的题。已经稳住的会先离开这里。」

列表里每条只显示题干，以及学生已经认识的状态：「正在熟悉」或「再巩固一下」。不显示答错次数、到期日、对错历史，也不显示「错过了」。分数题干仍用已有的横线分数，不改存储里的写法。

列表按域分成三组即可：平方、常用乘积、分数到小数。组内顺序与现有纸页一致，不按错次排列。某一组没有当前错题时，不留空标题。

列表不写到期日，也不区分「今天轮到」和「还没轮到」。孩子不需要先看懂调度才能开始。

没有当前错题时，不展示空收藏夹。一句：「现在没有要再写的错题。」主路回到首页开始今天的练习。

已经稳住的历史错题不设第二个标签页。上面那句「会先离开这里」就是全部说明。

# 3. 错题练习

本页主按钮是「练这些错题」。只要还有当前错题，这个按钮就可以开始，即使它们都还没到系统主动安排的日子。

进入后与今日训练相同：直接第一题，一题一屏，答错停住，学生按下一步才离开，本节内错题再现规则不变。做完或先停，都回到结束页，主按钮离开，不自动再开一段。

这一段含全部当前错题。已经轮到的排在还没轮到的前面。同一档内部打散，避免 `6×2`、`6×3`、`6×4` 这种能猜出下一题的串。多个域仍交错。未练过的题和已经很稳的题都不补进来。学生看不见「因为还没到期所以先不练」，也看不见洗牌规则。

# 4. 从错题本打印

错题本页底一个安静链接：「印这些题」。

它进入和首页、进度相同的选题页，不新做一种纸张样式。说明仍是：「选出要印的题。纸上没有答案。」

从这里进入时，仍是这同一个选题器。当前错题先出现在眼前，并且已经勾上。学生可以取消某一题，也可以展开并勾选其他已经练过的关系。不另做一份只含错题的选题器，也不另做一种纸。预览里只有勾上的题目和日期。不放正确率，不放「你错过了」，不放错过几次。答案仍必须另走已有的「答案单独一页」。

没有当前错题时，这个链接不把整份未练清单印出来。首页和进度仍可进入同一页，去勾已经练过的题。

不做本周、历史或已恢复错题的打印选项。

# 5. 页面状态

| 状态 | 学生看见 | 然后 |
| --- | --- | --- |
| 有当前错题 | 列表，以及「练这些错题」 | 进入一段错题练习。已轮到的在前，还没轮到的在后 |
| 没有当前错题 | 一句现在没有要再写的错题 | 回首页 |
| 打印环境做不到 | 沿用已有的「这个环境完不成打印。」 | 不提供换设备或二维码 |

# 6. 界面约束

UI Designer 只约束这个新入口，不新开设计系统。

- 「错题本」使用首页已有安静链接的写法：无底，颜色弱于主按钮。
- 错题本页使用进度页已有的纸面列，不新做卡片墙。
- 不使用红色叉、计数徽章、火焰或「错了 N 次」。
- 打印预览继续用已有的 A4 纸面，也继续用同一个选题器。从错题本进来只改变一开始看见哪些题，不另做一份纸。

# 7. 与首页契约的关系

今日训练仍从首页「开始练习」进入。错题本是底部和首页都能到的一页，不是另一套调度。
