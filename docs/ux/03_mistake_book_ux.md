# 错题本交互

状态：待审阅。本文不是已冻结契约。通过审阅并 Freeze 之前，不实现。

本文只描述错题本这一条新路径。首页其余层级、今日训练、专项、进度、原来的打印，以及答错后停住、隔题再现，都保持已冻结的 UX。第 7 节的首页修订尚未写入 `docs/ux/02_ux_spec.md`。

# 1. 入口

错题本只有一个学生入口。

首页在现有两个安静链接旁，增加同级文字链接「错题本」。它弱于「开始今天的练习」，也不做成卡片、徽章或红点。链接上不写错过的次数。

进度页和原来的「印到纸上」不再各做一个错题入口。进度页仍列出还要再见到的关系，其中可以包含从未答错、只是还在熟悉的题。那不是错题本。

训练进行中仍然没有底部导航，不能从题目页跳进错题本。

# 2. 错题本页

打开后只有一块当前列表。

标题是「错题本」。下面一句：「这里是还要再写熟的题。已经稳住的会先离开这里。」

列表里每条只显示题干，以及学生已经认识的状态：「正在熟悉」或「再巩固一下」。不显示答错次数、到期日、对错历史，也不显示「错过了」。分数题干仍用已有的横线分数，不改存储里的写法。

列表按域分成三组即可：平方、常用乘积、分数到小数。组内顺序与现有纸页一致，不按错次排列。某一组没有当前错题时，不留空标题。

尚未到期的当前错题也出现在列表里。它们不带「明天」这类调度词。页上用一句说明：「还没轮到的，会在后面的练习里再见到。」

没有当前错题时，不展示空收藏夹。一句：「现在没有要再写的错题。」主路回到首页开始今天的练习。

已经稳住的历史错题不设第二个标签页。上面那句「会先离开这里」就是全部说明。

# 3. 错题练习

本页主按钮是「练这些错题」。只有存在已经轮到的当前错题时，这个按钮才可进入练习。

进入后与今日训练相同：直接第一题，一题一屏，答错停住，学生按下一步才离开，本节内错题再现规则不变。做完或先停，都回到结束页，主按钮离开，不自动再开一段。

这一段只含已经轮到的当前错题。多个域仍交错。没有轮到的当前错题留在列表里，不提前抽进这一段。未练过的题和已经很稳的题都不补进来。

若当前错题都还没轮到，按钮不可用，保留第 2 节那句说明。不另开一段「随便练练」。

# 4. 从错题本打印

错题本页底一个安静链接：「印这些题」。

它进入已有的打印预览，不新做一种纸张样式。进入前说明：「印的是错题本里这些题。纸上没有答案。」

默认范围是全部当前错题。可以再选一个域，选了也只印该域的当前错题。预览里只有题目和日期。不放正确率，不放「你错过了」。答案仍必须另走已有的「答案单独一页」。

没有当前错题时，不提供这份打印，也不改去印整份未练清单。

原来的首页「印到纸上」不变：仍是还不稳定的题，含从未答错的熟悉中题目。两份纸的入口不同，避免孩子分不清印出来的是哪一批。

不做本周、历史或已恢复错题的打印选项。

# 5. 页面状态

| 状态 | 学生看见 | 然后 |
| --- | --- | --- |
| 有当前错题，其中有的已经轮到 | 列表，以及「练这些错题」 | 进入一段错题练习 |
| 有当前错题，但都还没轮到 | 列表，按钮不可用，一句会在后面的练习里再见到 | 可以留下，或去印这些题 |
| 没有当前错题 | 一句现在没有要再写的错题 | 回首页 |
| 打印环境做不到 | 沿用已有的「这个环境完不成打印。」 | 不提供换设备或二维码 |

# 6. 界面约束

UI Designer 只约束这个新入口，不新开设计系统。

- 「错题本」使用首页已有安静链接的写法：无底，颜色弱于主按钮。
- 错题本页使用进度页已有的纸面列，不新做卡片墙。
- 不使用红色叉、计数徽章、火焰或「错了 N 次」。
- 打印预览继续用已有的 A4 纸面。变的只是题目从哪份列表来，以及进预览前的那一句说明。
