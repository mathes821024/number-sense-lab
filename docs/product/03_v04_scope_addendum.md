# v0.4 产品范围增补

状态：契约设计，供 Contract Gate。本文补充当前范围。`docs/product/01_prd.md` 里标明 v0.1 的句子仍然只描述 v0.1，不在这里改写。

学习条目以 `docs/curriculum/06_v04_content_contract.md` 和 `docs/curriculum/07_v04_relation_spec.md` 为准。

# 1. 这一版增加什么

在现有 122 条之上，增加五个可训练域，共 51 条。五域都进齐之后，可训练关系是 173 条。

学生仍是同一个人，仍做 5–10 分钟的短练习，仍不登录、不靠后端。开始练习仍是每天的主路径。新域是专项入口和目录里的关系，不是新的产品。

# 3. 专项里现在可以打开的方向

已有三张卡保持原名：平方、常用乘积、分数到小数。

v0.4 按发布打开：立方、半数与翻倍、补数、常见幂、凑整乘积家族。常见幂和凑整乘积家族不合成一张卡。

半数与翻倍替换原来的「倍数与因数」占位，不两张并存。因数对（给和与积，求两个数）不在本版。

规律探索、概念、例题、动画不是 v0.4 的训练域，也不作为练习页上的占位卡。它们属于以后的知识地图。练习页的分组见 `docs/ux/05_specialist_grouped_grid.md`。这一轮点「知识地图」仍是「敬请期待」。

# 4. 明确不做

- 不改判题、掌握、错题语义、打印语义。
- 不加答案类型，不加双值输入。
- 不加域级解锁、每日域配额、每节新题比例。
- 不加奇数半数、`pow-5-3`、37 家族记忆题。
- 不把知识地图、概念课做成这一版的训练。
