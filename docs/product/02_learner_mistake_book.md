# 学习者身份与错题本

本文只回答一件事：在不登录、不建后端的前提下，这台设备上的学习记录属于谁，以及孩子要的那一个错题本是什么。

# 1. 要解决的问题

现在的记录能回答「会不会」和「下一次什么时候再出现」，但身份等于整台设备上的那一份状态。孩子要的是一个错题本，不是再开一个题库，也不是把所有还没练熟的题都叫做错题。

不做这件事，以后每增加一族关系，都容易再长出一套错题入口和一套打印。

# 2. 产品决定

## 2.1 学习者

- 本阶段仍然只有一个正在使用的学习者。
- 不注册、不登录、不采集姓名。
- 第一次产生学习记录时，在本地生成一个 `learner_id`。它是这一份学习档案的内部主键。
- `learner_id` 不是设备号，不是浏览器指纹，也不是微信、抖音或支付宝的用户标识。
- 设备仍然是这份档案的存放处。首页那句「练习记录只保存在当前设备，不会自动同步到其他设备」保持不变。
- 清除本机数据后，这个 id 和档案一起消失。本阶段不提供导出、扫码或换机恢复。

以后若要跨端认成同一个人，绑定的是这个 `learner_id`，而不是临时把 openid 当成学习主键。绑定本身不在本阶段。

## 2.2 错题本是视图，不是第二套题库

错题本读取已经存在的作答和掌握状态。它不另存一份错题清单，不另写掌握规则，也不按知识族分册。

以后新的可训练关系，只要进入同一个学习者的 `relations`，就自动接受同一套进入、离开和再进入规则。小数到分数、循环小数、反向平方都不另做一本错题本。

## 2.3 两种错题

| 名称 | 含义 | 学生本阶段看得见吗 |
| --- | --- | --- |
| 当前错题 | 曾经答错过，并且现在仍是「正在熟悉」或「再巩固一下」 | 看得见，这是错题本的唯一列表 |
| 历史错题 | 曾经答错过。已经重新「已经很稳」的也算在内 | 数据保留。本阶段不另做历史页、历史打印或第二个入口 |

只答对、从未答错的「正在熟悉」不是错题。它继续出现在今日训练和专项里。打印时它默认不勾，学生可以自己勾上。

从未练过的关系不是错题。

## 2.4 进入、离开、再进入

- 第一次被记下的答错：进入当前错题。空提交、只按小数点、以及值对但还没约成最简，仍然不算答错，也不产生错题记录。
- 同一天的纠正可以把「再巩固一下」回到「正在熟悉」。只要还没重新变稳，它留在当前错题。
- 出现频率下降沿用已有调度：同一天连对不拉长间隔，新的一天答对才升级。错题本不另设冷却。
- 重新达到「已经很稳」：离开当前错题，留在历史里。到期的低频复查仍走今日训练里已有的 stable 补位，不因为「曾经错过」被拉回错题练习。
- 已经很稳之后再次答错：立刻回到当前错题。答错前积累的稳定资格如何作废，沿用已实现的恢复边界，本文不另写一套。

## 2.5 错题练习

调度决定系统什么时候主动把一条关系拿出来。它不禁止学习者主动练一条已经在错题本里的关系。

今日训练和专项仍是系统主动选题，继续只抽已到期的。错题练习是孩子从错题本自己点进去的，可以练全部当前错题。已到期的排在尚未到期的前面。多个域仍交错。未练过的、以及已经恢复为「已经很稳」的，都不进入这一段。

尚未到期却被主动练到时，沿用已有调度，不另写一套：答对不拉长间隔，保留原来的到期日；答错则按答错规则重新安排。

## 2.6 错题打印

打印只有一套选题页。首页、进度和错题本都进入它。

当前错题默认勾选。只答对过、从未进入当前错题的题默认不勾，学生可以自己勾上。勾选不改变掌握，也不把一道题写进或写出错题本。错题本的定义不变：曾经答错过，并且还没有重新变得很稳。不改成「最近一次答错才算错题」。

纸上只有勾上的题目。答案仍须另走一步。不做「本周错题」，不印已经恢复的历史错题，不把全部未练关系印成一张海报。

## 2.7 现在做，和明确不做

现在做，且只在 Freeze 之后才实现：

- 本地 `learner_id`，以及把现有 v2 记录放进这一个学习者名下
- 一个错题本入口、一张当前错题列表、一次错题练习、一种当前错题打印

明确不做：

- 账号、登录、后端、云同步、多设备恢复
- 多个学习者的切换界面
- 平台 openid 绑定
- 错题历史浏览、本周错题、按错次排序
- 新课程、新记忆钩子文案、把钩子印到纸上
- 家长端、导出文件、二维码转移

# 3. 学生故事

作为一个初中生，我希望只有一个叫「错题本」的地方，这样我不用在进度、打印和专项里猜哪些才是错过的题。

作为一个初中生，我希望已经写稳的题离开这个列表，但系统仍记得我曾经错过，这样它不是一本只会变厚的收藏夹。

作为一个初中生，我希望错题练习结束时就停，并且没有把我没错过的新题塞进来。

# 4. 怎样算做成

- 同一台设备上，已有的掌握状态、作答、到期日、未完成的一段练习和声音开关都还在，并且挂在同一个 `learner_id` 下。
- 只答对过的关系不出现在错题本。
- 答错过又重新变稳的关系不出现在当前列表，数据仍能判断它属于历史错题。
- 变稳后再答错，会回到当前列表。
- 只要还有当前错题，「练这些错题」就可以开始，包括尚未到期的。已到期的排在前面。未练和已恢复的稳定关系不进入这一段。今日训练和专项仍只按到期选题。
- 打印是同一选题页。当前错题默认勾选，其他练过的题默认不勾。题目和答案不同时可见。勾选不改变掌握。
- 新的可训练关系不需要单独登记进错题本。

# 5. 非目标

本文件不规定颜色、字号、UUID 的代码写法、localStorage 的容量阈值，也不改调度阶梯的天数。

# 6. 学习内容怎么接

Math Learning Designer 的约束：错题本不生产新的记忆钩子。答错后的反馈仍是已有的正确关系加一句结构提示。钩子、分步和相关例子留在内容条目上，按关系 id 读取，不抄进学习者的作答记录。

以后内容可以增加视觉链、变换步骤或合理性检查。那些字段属于内容层。错题本只按关系 id 找到它们，不因字段变多而另建错题状态。
