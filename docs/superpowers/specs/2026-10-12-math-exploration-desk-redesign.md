## 1. 设计结论

首版采用「数学探索台」方向：以温暖的数学实验室为底色，用数学关系、学习层级和安静陪伴替代卡片墙、强刺激和居高临下的训练语气。

这次重构的目标不是把页面装饰得更热闹，而是让孩子在打开应用时感到：

1. 这里有人陪我一起观察和理解，不是在监督、排名或审判我；
2. 我能看见自己正在学习什么、它与下一步有什么关系；
3. 数学结构本身就是可探索、可操作、值得好奇的；
4. 每次只走一小段，也能获得真实、可积累的进步。

视觉配比采用：70% 数学探索台、20% 研究手册、10% 轻量探索路径。首版不做游戏化地图、积分、连胜、等级锁、排行榜或连续打卡压力。

## 2. 产品情感中心

### 2.1 主张

**陪孩子看见数字之间的关系，把会做慢慢练成真正可依靠的数感。**

产品的“陪伴”不是持续夸奖，也不是用角色替代教学，而是稳定地做到：

- 不催速度，不用题量证明努力；
- 不把一次错误解释成能力不足；
- 在孩子需要时提供结构、提示和下一小步；
- 在孩子思考时保持安静；
- 允许停下，也允许回来继续；
- 让进步表现为关系逐渐熟悉，而不是被外部奖励牵引。

### 2.2 语气边界

推荐：

- 「我们一起看看这两个数的位置。」
- 「先别急着算，看看哪里可以凑整。」
- 「这条关系还在变熟，过一会儿会再见到它。」
- 「今天先走到这里，也很好。」
- 「想继续时，我们再从这里出发。」

避免：

- 「你必须掌握」；
- 「这么简单怎么还会错」；
- 「坚持打卡，不要掉队」；
- 「击败了多少同学」；
- 每题都用「太棒了」「你真聪明」等空泛评价；
- 用吉祥物代表家长、老师或系统对孩子进行评判。

## 3. 首版页面结构

### 3.1 首页

首页继续把今日练习作为唯一主行动。完成态删除「再练一小段」，避免与「专项练习」重复。

完成态结构：

```text
吉祥物 + 今天这段练完了
一句与本次学习有关的安静反馈

[ 看看这次 ]

下一步
专项练习    错题本    最近进步
```

「下一步」使用紧凑入口，不再重复三张同等重量的大卡片。设备本地存储说明从首页移到「我的 > 数据与隐私」。

首页不新增自动续练、奖励领取、连续天数或提醒焦虑。用户主动进入专项练习，已经足以表达“还想多练一点”。

### 3.2 专项练习：事实领域实验架

保留事实领域的三个语义分组：

- 幂与乘方；
- 乘法与凑整；
- 数与分数。

但取消「彩色大容器包白色卡片」的多层套叠。每组只保留一层轻背景或分区标记，组内项目改成紧凑的实验项目行：

```text
[数学结构图]  平方
               正在熟悉  ━━━━○
```

数学结构图优先表达含义：平方阵列、立方体、指数上标、乘法点阵、凑整缺口、分数带、倍半关系。图标是主题资产，可替换外观，但不能改变 `domain_id` 或学习语义。

### 3.3 七年级有理数：能力路径

八个技能不再表现为八张完全平权的双列卡片，而是组织为四个学习阶段：

```text
01 认识有理数
   正负数、相反数与绝对值
   有理数比较

02 掌握四则
   整数加减
   整数乘除

03 进入分数
   分数加减
   分数乘除

04 综合运用
   有理数乘方
   有理数混合运算
```

手机上用一条细的纵向关系线串联四阶段。每个技能是一行独立可点击目标，包含：

- 数学语义小图标；
- 技能名称；
- 当前难度带；
- 当前熟悉状态；
- 进入提示。

建议图形：

| 技能 | 数学结构图 |
| --- | --- |
| 正负数、相反数与绝对值 | 带零点和双向箭头的数轴 |
| 有理数比较 | 数轴上的两个点与方向 |
| 整数加减 | 正负筹码或方向移动 |
| 整数乘除 | 点阵分组与拆组 |
| 分数加减 | 两条分数带对齐 |
| 分数乘除 | 面积模型或约分关系线 |
| 有理数乘方 | 底数、括号和右上角指数 |
| 有理数混合运算 | 括号树与运算顺序 |

四阶段只是展示层级，不是新的学习身份，不进入调度、掌握、错题或持久化数据。现有八个 `skill_id` 保持不变，所有技能继续可直接进入，不设置锁关。

### 3.4 错题本

首版只展示「当前错题」，移除不可用的「已掌握」「全部」标签和「敬请期待」占位。

列表继续采用纸面账页与细分隔线，不做新卡片墙。单题状态下补足上下文，而不是用空白填满页面：

```text
当前要重新写熟的关系

常用乘积
6 × 12 = □
上次还没有写稳，隔开几题后再确认一次

[ 练这 1 题 ]     印这些题
```

空状态使用安静姿态吉祥物和一句中性说明：「现在没有需要重新写熟的题。」不使用庆祝海报，也不宣称孩子已经永久掌握全部内容。

### 3.5 我的

「我的」在首版成为真实页面，而不是 toast 占位。页面包含：

1. 本地昵称；
2. 当前学习概览；
3. 声音与减少动态说明；
4. 数据与隐私；
5. 关于数感训练场；
6. 版本与项目说明。

昵称是可选的本地展示偏好，建议限制为 1–12 个汉字等效长度。昵称不得成为 `learner_id`，不得改写现有练习记录、调度、掌握状态或历史题目身份。具体存储方案必须在实施计划中选择兼容方式，并覆盖旧设备无昵称的默认路径。

首版不加入头像上传、账号、家庭成员切换、云同步或社交展示。

## 4. 产品介绍正式文案

### 关于数感训练场

> 数感训练场，是父母陪孩子一起做的一间数学实验室。
>
> 我们发现，孩子有时并不是不懂数学，而是一些重要的数字关系还没有熟悉到可以自然地想起来。计算一旦处处停顿，后面的理解也会变得更辛苦。
>
> 所以，我们想做一个真正能陪伴孩子的工具：不催速度，不比排名，不用题量制造压力。每天只练一小段，在一次次观察、尝试和回想中，把零散的数字连接成越来越清楚的关系。
>
> 我们希望孩子在这里得到的，不只是更多正确答案，而是面对数字时更从容的感觉，更可靠的计算直觉，以及继续学习数学的信心。

### 我们相信

- 数感不是天生的标签，它可以在理解和练习中慢慢生长；
- 错误不是惩罚的理由，而是找到下一步帮助的线索；
- 真正的熟练不是刷得更多，而是能够看见关系、选择方法、检查结果；
- 好的学习工具应该尊重孩子的节奏，也让父母更安心地陪伴。

### 数据说明

> 当前练习记录默认只保存在这台设备上，不会自动同步到其他设备。

产品介绍统一使用「父母」「家长」或「陪孩子学习的人」，不把项目描述限定为“父亲为孩子制作”，以适配实际小程序主体和更广泛的家庭使用场景。

## 5. 吉祥物：安静的实验伙伴

吉祥物使用四类语义状态：

| 状态 | 使用位置 | 行为 |
| --- | --- | --- |
| 欢迎 | 首页、专项页顶部 | 一次短暂出现或招手 |
| 思考 | 错题、原理入口 | 看向关系图或轻微思考 |
| 发现 | 完成一段、看见关系 | 短暂抬笔或眼神变化 |
| 休息 | 结束、空状态 | 安静停留，不催继续 |

吉祥物可以在首页、专项页、完成页和「我的」页成为较明显的视觉角色；在正式答题、键盘、正确反馈、错误反馈和打印页面中继续保持缺席，避免打断思考。

互动限于展示当前页面的一条有用观察或说明，不产生积分、奖励、隐藏学习状态或新的调度逻辑。

动效规则：

- 页面进入或状态变化时播放一次；
- 单次短、可打断、不循环弹跳；
- 低动态环境直接显示最终姿态；
- 无动画、无图片、无声音时仍能完成全部流程；
- 动效不决定按钮是否可用，也不参与判题与学习状态。

## 6. 视觉语言

整体仍是 `math-lab` / 澄蓝数学实验室主题，不在首版新增主题切换器。

视觉调整：

- 减少约一半的嵌套白卡片和大圆角容器；
- 使用细线、刻度、数轴、分数横线、关系箭头和阶段路径建立科学感；
- 保留米白纸感、实验绿和澄蓝，颜色承担语义，不为热闹而平均铺色；
- 状态不只靠颜色表达；
- 阴影更轻，主要依靠空间、线条和层级分隔；
- 数学语义由 DOM 文本与 CSS 结构共同表达，不把必要信息烘焙进图片；
- 学生可见分数继续使用横线分数；幂继续使用教科书上标。

## 7. 数据与学习边界

本次重构不得修改：

- 判题与答案规范；
- 掌握四态；
- 调度与错题再现；
- `relation_id`、`skill_id`、持久化 `exercise_id`；
- 七年级生成器版本与既有会话兼容；
- 打印语义；
- 今日训练、专项训练、错题本之间的题目范围。

新增阶段、关系线、图标、昵称和吉祥物状态均属于展示或本地偏好。任何实现若需要改变上述学习或数据契约，必须报告 `CONTRACT_CONFLICT` 或 `DATA_MIGRATION_RISK`，不得在视觉实现中顺手改写。

## 8. 跨端与无障碍

同一共享 UI 服务 H5 和微信首发，并为抖音、支付宝保留平台适配边界。

实施验收至少覆盖：

- 320、375、390、430 宽移动视口；
- H5 键盘焦点、200% 缩放、读屏文本和控制台；
- 微信开发者工具与真机安全区；
- 点击目标不小于 44×44 CSS px 等效面积；
- 最长技能名、负分数、上标、横线分数不溢出；
- `prefers-reduced-motion` 或平台等效低动态路径；
- 业务静态资源无 404；
- 底部导航不遮挡最后一个可点击项目。

截图与自动化检查只能作为证据，不能替代 Owner 与家庭的真实设备体验验收。

## 11. 成功标准

Owner 与家庭真实体验应能回答“是”：

1. 孩子能看懂七年级八个技能之间的大致层级，而不是面对八张平权卡片；
2. 页面比当前版本更少依赖卡片，但入口仍明显、可点；
3. 吉祥物更有存在感和陪伴感，却不干扰答题；
4. 「我的」不再像未完成功能，并清楚说明产品为什么存在；
5. 文案没有排名、催促、羞辱、空泛夸奖或居高临下的压力；
6. H5 与微信核心路径、历史学习记录和题目身份不因视觉重构改变；
7. 孩子愿意再次打开应用，原因来自清楚、友好和有发现感，而不是外部奖励压力。
