# DESIGN.md — Option A 澄蓝实验室

状态：视觉候选，不是冻结契约。不改产品、UX 或现有原型。

## Design philosophy

首页像一间明亮的数学实验室：有几何、有浅层空间，让人想走进去。进入题目后，实验室退到后面，只留下大数字和键盘。愉悦来自形状和完成时的一颗安静光点，不来自奖励。

## Visual atmosphere

Bright but Calm。青绿色水面，少量暖沙色。轻科技，不是企业后台，也不是小学乐园。

## Color tokens

| Token | Value | Use |
| --- | --- | --- |
| ink | `#102033` | 正文、题目 |
| ink-soft | `#4D6474` | 辅助说明 |
| bg | `#E5F4F3` | 页面底 |
| surface | `#F7FFFE` | 卡片、答案区、按键 |
| action | `#0C7C86` | 主按钮、强调 |
| action-deep | `#085E66` | 按下 |
| sand | `#F3C15B` | 主视觉高光、完成光点 |
| correct | `#0E7A56` | 对了 |
| notice | `#8A5A2B` | 答错标记「看这里」 |
| notice-surface | `#E7EEF8` | 答错关系块，偏冷，不发红 |

主按钮白字对 `#0C7C86`，正文 `#102033` 对 `#E5F4F3`。实现前用对比度工具复核，正文目标至少 4.5:1，大标题至少 3:1。

## Type scale

- 标题：Fraunces，光学尺寸可变，字重 560。首页标题约 40px，题目约 52px。
- 界面：Sora。说明 15px，主按钮 17px，按键数字 22px。
- 中文回退：PingFang SC、Noto Sans SC。
- 不用 Inter、Roboto、Arial、Open Sans、Helvetica。

## Spacing

页面左右 20px。区块之间 18px。键盘间距 8px。内容最大宽度 430px 的手机画幅，平板居中，不超过 720px。

## Corner radius

卡片 22px。主视觉内层 22px，外层 28px。主按钮全圆。按键 16px。

## Shadows

一层很浅的投影：`0 18px 40px rgba(16, 32, 51, 0.06)`。主按钮可带同色浅影。不要厚重黑色阴影，不要玻璃拟态面板。

## Surfaces

底是浅青渐变加两处光斑。卡片是半透明白。题目页改成更平的底，少光斑，让数字成为唯一焦点。

## Primary CTA

全宽胶囊。文案「开始今天的练习」，副文案「大约 5～10 分钟」。结束页同一形状，文案「先到这里」。

## Secondary CTA

文字按钮，墨色偏软。首页是「最近练得怎么样」「印到纸上」。结束页是「看看最近练得怎么样」「再练一小段」。

## Training question

Fraunces 大数字，居中偏上。答案区是白底圆角空槽。一次一题。

## Keypad

3 列。数字键至少 56px 高。提交键跨三列，使用 action 色。整数题不出现小数点。分数题才出现一个小数点键。

## Correct state

对勾和「对」用 correct 色，停留后进入下一题。不放烟花，不改计数语义。

## Wrong state

题目缩小并降为辅助色。正确关系放进 notice-surface 圆角块，成为新的中心。一条结构提示。标记用 notice 色的「○ 看这里」。主按钮变为「下一题」。不出现「你错了」，不提供立刻重做。

## Cards

首页三个训练域是等宽小卡，只写域名，不写题量。卡与卡同一语言，不做成三个不同 App。

## Icons

细线几何：立方线框、平方、乘号、分数条。线宽一致，圆角端点。不用卡通人物。

## Illustrations

只在首页主视觉使用：半透明立方线框加一个数字关系，例如 15² 与 225。做题页不放插画。

## Motion

主视觉里的线框可以极慢漂一点。答对时关系数字轻轻落到正确色，400–700ms 后换题。答错时关系块从下方 8px 进入，一次，不弹跳。完成页光点出现即可。不做连击、金币、震动庆祝。

## Accessibility

可点区域至少 44px，手机键盘至少 56px。颜色不是唯一状态：对了有「对」，错了有关系句和「看这里」。动效可随系统「减少动态效果」关闭。

## Responsive rules

手机优先。短横屏时键盘改为至少 44px，题目缩小，提交仍留在视口内。桌面保持同一窄栏，不改成仪表盘。

## Do

- 首页比做题页更有画面。
- 三个域用同一套几何语言，只换符号。
- 完成感停在一颗光点。

## Don't

- 不要幼儿园卡通、糖果色铺满、VIP、商城、奖励币、连胜、排行榜。
- 不要底部多 Tab。
- 不要把做题页做成海报。
- 不要深色 SaaS 玻璃风。
