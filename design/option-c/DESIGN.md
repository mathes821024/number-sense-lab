# DESIGN.md — Option C 数感工作室

状态：视觉候选，不是冻结契约。不改产品、UX 或现有原型。

## Design philosophy

像一本给青少年的数学刊物，不是一张练习纸，也不是后台。吸引力来自巨大的标题、一条热色和很克制的版面。装饰很少，记忆点是字和一条橙色标记。

## Visual atmosphere

Modern Number Studio。暖纸色，近黑文字，一处电光蓝，一处热橙。编辑感，仍然是教育产品，不是品牌官网。

## Color tokens

| Token | Value | Use |
| --- | --- | --- |
| ink | `#161616` | 正文、题目、主按钮 |
| ink-soft | `#5E584F` | 辅助说明 |
| bg | `#F4EFE6` | 页面底 |
| action | `#2436F2` | 提交、英文小标 |
| accent | `#FF5A36` | 短色条、域符号、答错标记、一颗星 |
| correct | `#2436F2` | 「对」，与提交同色，避免再引入绿色系统 |

白字对 `#161616` 和 `#2436F2`。正文对 `#F4EFE6`。实现前复核，正文至少 4.5:1。热橙只用于小面积标记，不铺满按钮，避免对比不足。

## Type scale

标题：Newsreader，字重 500。首页标题约 52px，题目约 76px，结束页「练完了」可以到 72px。
界面：Sora。说明 16px，行按钮 18px，按键 20px。
中文标题若 Newsreader 缺字，回退到同一字号的宋/明体系，不回退到黑体标题。界面中文用 PingFang SC、Noto Sans SC。
不用 Inter、Roboto、Arial。

## Spacing

左右 22px。首页标题与按钮之间 28px。域列表用 16px 垂直内边距。键盘间距 8px。窄栏居中。

## Corner radius

主按钮 4px。按键直角或 4px。不使用大圆角胶囊。

## Shadows

基本无阴影。层次靠字号、细线和一条 8px 色条。

## Surfaces

平涂暖纸。没有渐变卡片，没有玻璃。域入口是通栏分割线列表。

## Primary CTA

贴合文字的深色矩形按钮，不是全宽糖果按钮。文案「开始今天的练习」，副文案「大约 5～10 分钟」。结束页同一按钮写「先到这里」。

## Secondary CTA

细线列表或文字按钮。「最近练得怎么样」「印到纸上」不抢主按钮。

## Training question

题目几乎占上半屏，只保留数字关系。答案区是一条 2px 底线，不是输入卡片。

## Keypad

线框键，高度至少 52px，手机上仍不低于 56px 的可点目标时，用内边距补足。提交键跨列，action 蓝底白字。整数题无小数点。

## Correct state

题目颜色切到 action，旁边「对」。停留后换题。无庆祝插画。

## Wrong state

题目变辅助色。正确关系用 Newsreader 大字，左侧 6px accent 色条。一句提示。标记「看这里」。按钮「下一题」。不写「你错了」，不立刻重做。

## Cards

这个方向尽量不用卡片。三个域是同一条分割线里的三行，右侧一个衬线符号。进度页同样是短列表，不是仪表盘。

## Icons

不用图标库插画。域识别就是 x²、×、¾ 三个字符。

## Illustrations

不做场景插画。若以后需要主视觉，只允许一条几何细线和一个大数字，不加人。

## Motion

几乎静止。换题是直接替换。答错色条不滑动。若要有动作，只允许 200ms 的颜色变化。完成页一颗星直接出现。

## Accessibility

大字号有利于阅读。蓝与橙都不单独承担状态，旁边始终有文字。键盘目标不小于 44px。

## Responsive rules

手机优先，版面保持单栏海报。短横屏缩小题目字号，键盘至少 44px，提交留在视口内。桌面不改成多栏营销页。

## Do

- 让标题和题目大到成为品牌。
- 全站只用一条热色做标记。
- 做题时比首页更空。

## Don't

- 不要再加第三套强调色。
- 不要卡片网格、渐变球、3D 物体。
- 不要做成企业 SaaS、金融看板或通用落地页。
- 不要奖励币、连胜、排行榜、卡通角色。
