# DESIGN.md — Option B 暖数方块

状态：视觉候选，不是冻结契约。不改产品、UX 或现有原型。

## Design philosophy

数字关系做成可以碰的方块。颜色更暖，形状更圆，按下去有一块厚度。有趣，但不幼儿化：没有人物，没有商店，没有金币。

## Visual atmosphere

Soft Learning Playground。桃底、珊瑚主按钮、奶油黄和叶绿色块。像一套数学教具，不是卡通乐园。

## Color tokens

| Token | Value | Use |
| --- | --- | --- |
| ink | `#2C211C` | 正文、题目 |
| ink-soft | `#7A6458` | 辅助说明 |
| bg | `#FFF1E4` | 页面底 |
| surface | `#FFFAF6` | 方块、按键 |
| action | `#E15A3A` | 主按钮 |
| action-deep | `#B8432C` | 按钮厚度 |
| leaf | `#1F7A62` | 做题页提交、乘积块 |
| butter | `#F6C453` | 平方块、完成块 |
| butter-deep | `#E0AA3A` | 完成块厚度 |
| notice-surface | `#F8E2D4` | 答错关系块 |
| notice-deep | `#E7C3AD` | 关系块厚度 |

白字对 `#E15A3A` 和 `#1F7A62`。正文 `#2C211C` 对 `#FFF1E4`。实现前复核对比度，正文至少 4.5:1。

## Type scale

Plus Jakarta Sans。首页标题约 34px，字重 800。题目约 56px。说明 16px。按键数字 22px。中文回退 PingFang SC、Noto Sans SC。不用 Inter、Roboto、Arial。

## Spacing

左右 18px。方块间距 12px。键盘间距 10px。窄栏居中，最大约 720px。

## Corner radius

大方块 28px。域符号块 18px。主按钮 22px。按键 18px。

## Shadows

用同色实心厚度，不用模糊大阴影。主按钮 `0 8px 0 #B8432C`。按键 `0 5px 0 #EDD3C3`。这是触感，不是拟物皮肤。

## Surfaces

暖色平涂底，角落一块奶油光。卡片是暖白。做题页保留厚度，但拿掉多余色块，避免题目被装饰抢走。

## Primary CTA

全宽圆角矩形，珊瑚底，白字。「开始今天的练习」加「大约 5～10 分钟」。结束页同一按钮写「先到这里」。

## Secondary CTA

文字链，暖灰色，字重偏高。不做成第二颗彩色按钮。

## Training question

超粗大数字。答案槽是白底、内描边的圆角矩形。

## Keypad

3 列，键高至少 58px。提交键用 leaf，和首页珊瑚分开：首页邀请是暖的，提交是稳定的。整数题无小数点。

## Correct state

数字落到 leaf 色，出现「对」。不撒彩纸。

## Wrong state

题目降级。关系放在更暖的厚度块里。提示一句。标记「○ 看这里」用珊瑚，但是小字。按钮「下一题」。不写「你错了」，不立刻重做。

## Cards

三个域是横条方块：左边符号，右边域名和一句很短的关系说明。符号色不同，结构相同。不写题量，不写商城。

## Icons

方块里的 x²、×、¾。粗、几何、无描边人物。

## Illustrations

不另做场景插画。符号块就是插画。完成页是一块奶油色圆角方块，不是太阳脸。

## Motion

按下时厚度减少 2px，松手恢复。答错块一次落下。完成方块不旋转、不弹跳。系统要求减少动态时，厚度保持静止。

## Accessibility

键和主按钮都大于 44px。状态同时有颜色和文字。珊瑚不是唯一错误信号。

## Responsive rules

手机优先。短横屏减小键高到 44px，并保证提交留在视口内。桌面不展开成多栏仪表盘。

## Do

- 用厚度表达「可以碰」。
- 三个域颜色不同，骨架相同。
- 做题时减少色块数量。

## Don't

- 不要大眼睛角色、贴纸爆炸、奖励币、连胜火焰。
- 不要每个方块一种完全不同的插画风格。
- 不要把厚度做成厚重拟物或 3D 游戏按钮。
