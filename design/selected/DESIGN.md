# DESIGN.md — A+ 澄蓝数学实验室

状态：Owner 选定的视觉方向候选。不是 Contract Freeze。不改产品、UX，也不改 `prototype/`。

## Identity

数感训练场在读到字之前，像一间可以走进去的数学实验室。明亮、有空间、有可以碰的数学物体。科技感来自几何、层次和关系，不来自深色大屏或霓虹。

长期原则：首页负责「让我想进去」，做题页负责「让我静下来」。

## Visual atmosphere

Bright but Calm。浅青空间里有一层很淡的坐标网格。主视觉是半透明的线框立方和一条数字关系。年龄感大约 12～15 岁。

白字对 `#0C7C86` 大约 4.9:1，用于大按钮。正文 `#102033` 对 `#E7F6F4`。实现前再复核。沙色和蓝色只做图形，不单独做小字。

## Typography

- 标题和题目：Fraunces，字重 560。首页标题约 40px，题目约 52px。
- 界面：Sora。说明 15px，主按钮 17px，按键数字 22px。
- 中文回退：PingFang SC、Noto Sans SC。标题缺字时用宋/明体系，不退回黑体标题。
- 不用 Inter、Roboto、Arial、Open Sans、Helvetica。
- 从 C 借来的是层级和留白，不是海报式超大标题。

## Spacing

手机左右 20px。内容栏最宽 440px，更宽的屏幕只把同一栏居中，不改成仪表盘。区块间距 16–22px。键盘间距 8px。

## Corner radius

主视觉 28px。域卡片 18px。按键 16px。主按钮全圆。完成标记是略微转动的 18px 圆角块，不是笑脸。

## Shadows and depth

主按钮 `0 3px 0 #085E66`。按下时下移 2px，厚度剩 1px。按键 `0 2px 0`，按下下移 1px。这是从 B 借的触感，颜色仍是青绿，不是珊瑚玩具块。

主视觉用投影和内高光表达空间，不用厚玻璃拟态，不用霓虹外发光。

## Surfaces

底是浅青，加上 28px 的淡网格。首页主视觉是青绿渐变里的几何。做题页保留同一层很淡的网格，不再放主视觉。

## Primary CTA

全宽胶囊。「开始今天的练习」，副文案「大约 5～10 分钟」。结束页同一按钮写「先到这里」。答错页同一按钮写「下一题」。

## Secondary CTA

文字按钮。「最近练得怎么样」「印到纸上」。结束页是「看看最近练得怎么样」「再练一小段」。

## Hero

只出现在首页。内容是：半透明立方、一层更浅的暖色线框、淡坐标格、一个点、以及 `15² → 225`。文案是「今日实验」。立方可以极慢浮动。系统要求减少动态时，浮动停止。

## Domain cards

三张卡同一骨架：左边一个数学物体，右边域名和一句很短的话。

- 平方：四块面积
- 常用乘积：点阵
- 分数到小数：一条分成四份、涂三份的条

识别色只留在小图形上。不写成三个 App，不写题量。

## Mathematical visual assets

可复用的物体：面积块、线框立方、坐标格、分数条、数轴片段、点、乘法点阵、关系箭头。它们要像可以操作的数学对象。无人、无卡通、无电路板、无大脑图形。

## Integer keypad

题目示例 `15² = ?`。键为 1–9，第四行左侧是与小数点同尺寸的空位，然后是 0、删除，最下是提交。不出现「.」。空位是为了和分数题对齐，避免键盘跳动。

## Decimal keypad

题目示例 `3/4 = ?`。第四行左侧是「.」，0 和删除的位置与整数题相同。真实产品里小数点只能输入一次。本文件只规定视觉位置。

## Correct state

对勾圆、「对」，以及绿色的正确关系，例如 `15² = 225`。短停后进入下一题。不放烟花。

## Wrong state

原题降为辅助色。正确关系放进冷色块，成为中心。一句结构提示。「○ 看这里」。按钮「下一题」。不写「你错了」，不提供立刻重做。

## Completion

一块青绿与暖沙组成的小几何，加上「练完了」。主按钮是停下，不是再开一局。

## Motion

首页立方慢速浮动。按钮按下压缩 1–2px。答错块不弹跳。做对不庆祝。`prefers-reduced-motion: reduce` 时关掉浮动。

## Future 3D compatibility

现在的立方、网格和关系是平面里的空间暗示，用 SVG 就能画。以后可以沿同一物体语言走到 Canvas，再走到 Three.js / WebGL，让首页或知识解释里的数学对象动起来。Three.js 尚未实现，也还不是架构决定。做题页不把整个场景搬进去。

## Accessibility

按键至少 56px，主按钮至少 58px。状态同时有颜色和文字。沙色、蓝色不单独传递对错。动态可关闭。

## Responsive rules

手机优先。375、768、1280 都保持同一窄栏。1280 只是周围空间变多。题目在做题页里仍是最大的字。短横屏若以后实现，键盘可降到 44px，提交必须留在视口内。那是原型约束，本候选先保证这三档没有横向溢出。

## Do

- 首页比做题页更有画面。
- 科技感来自数学几何和浅层空间。
- 三个域用同一张卡，只换物体。
- 整数题和分数题的 0、删除、提交对齐。

## Don't

- 不要深色黑客背景、霓虹过载、电路板、AI 大脑、厚玻璃。
- 不要珊瑚主色、幼儿方块、卡通人物。
- 不要把首页立方搬进做题页。
- 不要在整数题放小数点。
- 不要金币、连胜、排行榜、VIP。
- 不要改流程、状态语义或现有原型。
